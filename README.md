# 第二部分：拉片与提示词工作流（Skill 使用手册）

> 本部分整理四个 Skill：**douyin-video-stats** 抓取互动数据，**video-shot-analysis** 做逐镜头拉片，**ai-video-storyboard-prompts** 将故事或脚本转换为分镜提示词，**scene-mannequin-blocking** 将站位说明变成场景中的人偶调度图。

## Skill 总览

| Skill | 定位 | 触发场景 | 主要产物 | 安装位置 |
| --- | --- | --- | --- | --- |
| **douyin-video-stats** | 抖音视频互动数据抓取 | 给抖音链接，要点赞 / 收藏 / 转发 / 评论数据 | Markdown 数据报告（基本信息 + 互动数据 + 热门评论表） | `.user_skills/douyin-video-stats/` |
| **video-shot-analysis** | 短视频逐镜头拉片分析 | 要"拉片 / 拆片 / 逐镜头拆解 / 分析爆款钩子、剪辑节奏、分镜" | 自包含 HTML 拉片档案 + 标准化 Markdown | `.user_skills/video-shot-analysis/` |
| **ai-video-storyboard-prompts** | 故事、剧本或分镜脚本转 AI 视频提示词 | 给故事或脚本，要求生成案例式逐镜头提示词 | 全片连续性设定 + 可逐条生成的中文分镜提示词 | `~/.codex/skills/ai-video-storyboard-prompts/` |
| **scene-mannequin-blocking** | 场景图与站位说明转人偶调度图 | 给底图、文字或圆圈站位，要求把人物位置画成人偶 | 标注图 + 无字图 + 可复用 JSON 配置 | 本项目 `.agents/skills/scene-mannequin-blocking/` |

**配合方式**：`douyin-video-stats` 取得视频外部数据，`video-shot-analysis` 拆解视频内部结构；从拉片笔记和模板学到的写法，可通过 `ai-video-storyboard-prompts` 用在新的故事或脚本上；需要直观锁定人物位置时，用 `scene-mannequin-blocking` 制作站位参考图。

## 一、douyin-video-stats —— 抖音互动数据抓取

**功能定位**：通过浏览器自动化（`mac_computer_use_tool` + `seed_browser_use`）访问抖音 Web 页面，从渲染后的 DOM 中提取互动数据与评论内容，不依赖第三方 API。

**触发场景**：提供抖音链接并要求"拿视频数据 / 看点赞收藏转发 / 拉评论区 / 抓前 N 条热门评论 / 输出 md"。链接支持 `/video/<id>`（独立页，评论抓取首选）、`/jingxuan?modal_id=<id>`（精选页）、`/user/<uid>?modal_id=<id>`（主页）。

**使用流程（7 步）**：

| 步骤 | 动作 | 关键点 |
| --- | --- | --- |
| 1. 打开视频页 | `bu.navigate(链接)` + `wait_for_load` | 确认 `page_info()` 标题匹配；主页链接弹窗可能不自动打开，重试导航并多等 3~5 秒 |
| 2. 提取互动数据 | `bu.js` 按 `data-e2e` 属性取数 | `video-player-digg`=点赞、`feed-comment-icon`=评论、`video-player-collect`=收藏、`video-player-share`=转发 |
| 3. 提取元数据 | 页面文本定位 | 标题 / 作者 / 发布时间 / 时长 / 合集 / AI 声明；主页场景另取粉丝数、IP 属地 |
| 4. 打开评论区 | 点击 `feed-comment-icon` | 主页弹窗约 10 条后出现"登录后可看更多"→ 切到独立页 `/video/<id>` 继续 |
| 5. 滚动加载 | 循环 `bu.scroll` + 计数 | 排除"加载中 / 登录后可看更多"占位，达标（如前 100 条）即停 |
| 6. 结构化解析 | `comment-mainContent` 直接子元素即评论块 | 解析用户名 / 正文 / 时间 / 地区 / 点赞 / 回复数 / 作者赞过 |
| 7. 整理输出 | 生成 Markdown | 基本信息表 + 互动数据表 + 热门评论 TOP N（按点赞降序） |

**踩坑记录**：

- `bu.js` 只接受表达式或 IIFE：传 `() => {...}` 返回空字典；须用 `(() => {...})()` 或直接表达式。
- 不要用 `bu.cdp`（当前环境报 Session not found）；`bu.http_get` 只能拿到 JS 壳，数据在渲染后 DOM 中。
- 点赞排序：页面值可能是"7.2 万"或"984"，排序前统一转数值（"万" ×10000）。
- 时间·地区正则：`^\d+[分钟小时天月年]前·`，地区为"·"后文本。
- 数字实时变化、万级为约数，报告中注明口径。

**产物结构（MD 三部分）**：`## 一、视频基本信息`（标题/作者含粉丝数/发布时间/时长/位置/备注/链接）；`## 二、互动数据`（点赞/评论/收藏/转发，页面约数）；`## 三、热门评论 TOP 100`（#/评论者/内容/点赞/时间/地区/回复数/备注）。

## 二、video-shot-analysis —— 逐镜头拉片分析

**功能定位**：对短视频（抖音 / 快手 / 视频号 / 小红书 / B 站爆款）做逐镜头拉片，把一条爆款拆成"可复算的证据（时间码）+ 可复用的方法（面向账号定位）"。默认面向 AI 剧情短片创作。

**触发场景**："拉片 / 拆片 / 逐镜头拆解 / 分析这条爆款 / 学习钩子、剪辑节奏、选题、分镜、转场、BGM、音效、字幕"；批量拉片、沉淀方法论；覆盖情感剧情、悬疑反转、纪实等体裁。

**交付产物（固定两份）**：

| 产物 | 说明 |
| --- | --- |
| **HTML 拉片档案** | 自包含单文件，8 章节（概览 / 情绪曲线 / 逐镜表 / 钩子 / 脚本 / 声音 / 字幕 / 方法论），内嵌 ECharts 图表与关键帧 |
| **标准化 Markdown** | YAML 元数据头 + 固定章节 + 枚举口径，供多条拉片横向汇总 |

**使用流程（10 步）**：

| 步骤 | 动作 | 关键点 |
| --- | --- | --- |
| 1. 确认输入 | 取得视频路径；明确拉片目的 / 账号定位 / 关注重点 / 交付形式 | 缺文件用 `interaction.ask` 索取，不猜内容 |
| 2. 抽取素材 | `bash scripts/extract_media.sh <视频> <out_dir>` | 产出 probe.json、切点、抽帧（1fps + 前 12s@4fps + 前 2s@8fps）、联系表、压缩音频/视频、RMS 能量曲线 |
| 3. 云端识别 | ASR（`audio/asr_audio.mp3`）+ OCR（`ocr_small.mp4`） | 只用脚本产出的压缩输入，大文件直传必超时 |
| 4. 通览分镜 | 逐张 `Read sheet_*.jpg`，结合切点 / ASR/OCR 建镜头清单 | 联系表单张须 ≤ 约 980px 宽 |
| 5. 分析 | 按 `references/analysis-framework.md` 出结论 | 所有结论回指时间码，不凭印象 |
| 6. 准备关键帧 | 每镜头选代表帧压到约 460px 宽，命名 `sXX.jpg` + `hero.jpg` | `ffmpeg -vf scale=460:-2 -q:v 4` |
| 7. 产出 HTML | 复制 `assets/html_template.html` 替换 `@@占位@@` | 图片静态写 `src="assets/sXX.jpg"`，勿用 JS 生成 |
| 8. 产出 Markdown | 复制 `assets/md_template.md` 替换占位 | YAML 字段名与章节顺序保持模板不变 |
| 9. 校验 | 内联 JS 跑 `node --check`；核对全部 `src` 存在；`embed_html.py` 输出 remaining refs=0 | ECharts 配置花括号易错，必查 |
| 10. 交付与清理 | `present_files` 交付 HTML 与 MD；要求精简时删中间产物 | 源视频在用户处，可随时重跑 2–3 步 |

**分析框架（9 维度，`references/analysis-framework.md`）**：

1. **维度总览**：选题｜钩子｜结构｜分镜/转场｜声音｜字幕，六件事固定回答。
2. **开头钩子**：前 3 秒决定停留、前 15 秒决定完播；钩子公式＝反常识细节＋1 秒感官特写快切＋一镜到底悬念现场＋记忆碎片对白。
3. **叙事结构**：情感剧情片高频结构＝现实钩子→年代闪回→时间蒙太奇→重逢→真实佐证（环形报恩）；八拍骨架。
4. **情绪工程**：前 80% 压着走→一次假高潮→真爆发；爆发点占比（peak/duration）是横向对比关键指标。
5. **声音设计**：BGM 三段式（低压铺底→假高潮涌起收回→全频段铺满）；音轨四层（BGM / 对白 / 转场音效 / 环境声）。
6. **字幕语法**：5 类字幕（对白 / 内心旁白 / 年份标签 / 新闻资料 / 落版主题词），位置即功能。
7. **选题公式**：真实小人物＋重复几十年的动作＋反常识数字＋一次重返/重逢。
8. **AI 剧情短片落地**：8 步工作流（色彩双轨 / 角色锚定 / 特写优先 / 转场统一 / 时间流逝 / 音轨四层 / 字幕三层 / 真实素材收尾）。
9. **字段口径与枚举**：YAML 字段名固定，取值用枚举表，保证多片可汇总。

**标准化 MD 关键字段（横向对比主键）**：
`id / title / source_platform / content_type / account_positioning / true_story / duration_sec / shot_count / montage_count / theme_tags / hook_type / structure_type / act_count / transition_signature / flash_points_sec / color_system / subtitle_layers / bgm_structure / emotion_peak_sec / emotion_valley_sec`

枚举示例：`hook_type` ∈ {反常识数字 / 物件特写快切 / 强冲突台词 / 一镜到底 / 记忆碎片对白 / 直接提问 / 结果前置 / 反差身份}；`transition_signature` ∈ {白闪+whoosh / 硬切 / 叠化 / 匹配剪辑 / 遮挡转场 / 运镜转场}。

**避坑经验**：

- 大文件上传超时 → 永远用 16k 单声道 mp3 做 ASR、720p CRF26 做 OCR。
- 联系表 ≤ 约 980px 宽；报告关键帧约 460px 宽。
- 转场与情绪点以"画面帧 + 音频峰值"双证据定位。
- HTML 图表 JS 花括号闭合是高频错误，`node --check` 必过再交付。
- 多条拉片严格统一字段口径与枚举，同义词只保留一个写法。

## 三、ai-video-storyboard-prompts —— 剧本转分镜提示词

**功能定位**：参考 `03_视频模板提示词整理/` 中的三组案例写法，将新故事、剧本或已有分镜脚本转换成可逐条用于 AI 视频生成的中文提示词。案例提供字段结构和连续性方法，不把原片的第一人称、川渝方言、年代、人物或品牌强加给新故事。

**调用方式**：在 Codex 对话中直接提供内容并要求“转换成分镜提示词”，或显式写 `$ai-video-storyboard-prompts`。例如：

```text
使用 $ai-video-storyboard-prompts，把下面的剧本转换成可逐条生成的分镜提示词。
保留原对白和结尾，不增加人物；采用客观镜头。

《未寄出的信》
内景，旧邮局，傍晚。雨水沿玻璃门往下淌……
```

**可提供的输入**：故事梗概、完整剧本、已有镜号的分镜脚本均可；角色、场景或道具参考图可选。有参考图时注明“`@图片1` = 林夏形象、`@图片2` = 旧邮局场景”等对应关系。也可指定视角、方言、画幅、单镜时长、音乐/字幕限制；未指定的设定由 Skill 保持中性，不编造参考图编号。

**默认输出**：先给简短的全片连续性设定，再按播放顺序逐镜写出“画面质感 → 色调光影 → 空间与场景 → 人物与氛围 → 镜头语言 → 时代与声音约束 → 画面”。每镜是可独立生成的连续片段，写清位置、动作、视线、道具状态和对白。已有分镜保留原镜号与明确的运镜；剧本按动作与对白拆镜；故事梗概补足最少的可见动作，但不改人物关系、关键情节或结局。

**使用边界**：该 Skill 只生成提示词，不自动生成视频或参考图。精确汉字（信件、招牌、屏幕文字）要保留原文，成片时仍需核字。Skill 位于 `~/.codex/skills/ai-video-storyboard-prompts/`，细则见其 `SKILL.md` 和 `references/case-derived-patterns.md`。

## 四、数据、拉片与创作配合使用

从爆款复盘到新故事创作的可选工作流：

```
1. douyin-video-stats   → 抓互动数据（点赞/收藏/转发/评论）与评论区
2. 下载/取得视频文件     → 本地 MP4（用户提供或另行下载）
3. video-shot-analysis  → 拉片：镜头/情绪/钩子/声音/字幕/方法论
4. 汇总                 → HTML 档案 + 标准化 MD + 互动数据，"数据+结构"双层复盘
5. ai-video-storyboard-prompts → 输入新故事/剧本/分镜，产出逐镜头生成提示词（创作时使用）
```

| 场景 | 用哪个 |
| --- | --- |
| 只看视频火不火、评论怎么说 | `douyin-video-stats` |
| 研究视频为什么火、怎么复刻 | `video-shot-analysis` |
| 完整爆款拆解（数据 + 结构） | 两者配合 |
| 把新故事、剧本或分镜转成生成提示词 | `ai-video-storyboard-prompts` |
| 根据场景图和站位文字／标记制作人偶图 | `scene-mannequin-blocking`（本项目） |
