# 场景人偶站位图：Skill 使用说明与提示词

本项目内安装的 skill：`scene-mannequin-blocking`。支持两种视图：在原场景照片上合成人偶；将已有站位图转换成偏俯视／顶视的三维空间示意，帮助看清被遮挡人物。可用于任意场景和人数，不限定厨房三人。

## 安装位置与调用

- Skill 入口：[SKILL.md](../.agents/skills/scene-mannequin-blocking/SKILL.md)
- 配置文档：[render-config.md](../.agents/skills/scene-mannequin-blocking/references/render-config.md)
- 渲染脚本：[render_mannequins.py](../.agents/skills/scene-mannequin-blocking/scripts/render_mannequins.py)
- 俯视流程与配置：[overhead-config.md](../.agents/skills/scene-mannequin-blocking/references/overhead-config.md)
- 俯视渲染脚本：[render_overhead.py](../.agents/skills/scene-mannequin-blocking/scripts/render_overhead.py)
- 可改写的俯视配置示例：[overhead-example.json](../.agents/skills/scene-mannequin-blocking/references/overhead-example.json)

这是项目级 skill，不安装到全局。在当前项目的 Codex 对话中写 `$scene-mannequin-blocking` 即可显式调用。新建 skill 后，若当前会话的技能列表尚未刷新，可以直接指定“读取并执行 `.agents/skills/scene-mannequin-blocking/SKILL.md`”；新会话可从项目技能目录发现它。

提供的材料越明确，站位越可靠：原图合成需要干净场景底图，以及站位文字、标记或指定场次的分镜；俯视转换可以直接指定已有人偶站位图，干净场景图可辅助辨认家具。可选角色名、颜色、动作时刻和输出目录。圆圈若在台面上，应说明它是操作点还是脚位；不清楚时由 AI 结合场景判断。

## 选择哪种视图

| 需要 | 调用方式 |
| --- | --- |
| 在照片中确定脚位、手部动作、远近比例 | 原图合成，保留原机位与图像尺寸 |
| 后景人物被挡住，想看全体站位 | 偏俯视，通常从55°左右开始 |
| 主要看人物脚位与家具平面关系 | 90°顶视 |

俯视图由单张照片近似建立空间模型后换机位，适合作为调度参考。人物位置、颜色与相对关系沿用指定图；墙体可剖开或降低以减少遮挡。它不表示照片外的结构已被精确恢复，也不自动改变成片机位。

## 提示词一：场景图＋文字站位

```text
使用 $scene-mannequin-blocking，制作场景人偶站位图。

场景底图：【图片路径或上传图】
人物站位：
1. 【角色甲】：【所在区域及与家具的关系】，身体朝【方向】，正在【动作】。
2. 【角色乙】：位于甲的【相对方位】，面向【对象】，正在【动作】。
3. 【按实际人数补充】

以【开场首帧／指定动作时刻】为准。
将人偶放到原场景中，脚落在地面，远近比例与透视一致，手部动作能接触对应物体。
保留原图尺寸、镜头视角和场景布局。
输出姓名标注版、无字版，以及可修改的站位 JSON 配置。
保存到：【项目内输出目录】。
```

## 提示词二：场景图＋站位标记

```text
使用 $scene-mannequin-blocking，把站位标记转换成场景中的人偶。

干净底图：【场景图路径】
站位参考：【带圆圈／箭头的图路径】
标记对应：【红=甲，黄=乙，蓝=丙；按实际填写】
动作补充：【各角色首帧动作、朝向；没有则结合图判断】

标记只用于理解站位。先判断圆圈表示脚位、操作点还是大致位置，
不要把台面、水槽上的圆圈直接当成脚底。
在干净底图上合成人偶，不沿用圆圈、箭头或机位标记。
输出姓名标注版、无字版和站位 JSON，保存到【目录】。
```


## 提示词四：把已有站位图转换成俯视图

```text
使用 $scene-mannequin-blocking，将【已有站位图路径】生成偏俯视站位图。
以这张图的人物位置、颜色、朝向和动作时刻为准，保留人物与家具的相对关系。
参考干净场景图：【路径，可选】。

从约55°偏俯视开始，让后景人物与桌椅位置可辨；必要时调整相机方位，
墙体可降低或剖开示意，不为露全人物而挪动剧情站位。
使用随附俯视渲染脚本，建立统一三维坐标与正常深度遮挡。
坐姿需对齐座面高度；手部与操作面接触；标签不挡头和手。
输出标注版、无字版和可复现的俯视JSON配置，保存到【项目目录】。
说明这是按单张图近似还原的空间示意，并指出原图与分镜重要道具状态差异。
```

只想看平面关系时，把“约55°偏俯视”改为“90°正顶视”；已有俯视JSON时，只改相机并另存新前缀，不重新安排人物。

## 直接运行俯视脚本

先查看[俯视配置说明](../.agents/skills/scene-mannequin-blocking/references/overhead-config.md)，复制并根据当前输入图改写示例。`position=[x,y,z]`是近似模型坐标，原图配置的归一化`foot`不能直接套入；脚本不自动从照片提取三维布局。

```sh
python .agents/skills/scene-mannequin-blocking/scripts/render_overhead.py \
  --config '项目内的俯视配置.json' \
  --output-prefix '项目资产目录/俯视图新版本'
```

相机用`camera.elevation_degrees`设置55或90，方位用`camera.azimuth_degrees`调整；人物配置保持不变。脚本会自动完整取景、绘制家具与人偶的深度遮挡，并输出`_标注.png`、`_无字.png`。可用`--check-only`检查配置；已有同名成果默认拒绝覆盖。


## 将人偶图交给视频／图片 AI 时

```text
@场景基准：用于锁定环境、布局、光线和透视。
@人偶站位图：仅参考人物站位、身体朝向、动作与远近比例。
@角色甲／乙参考图：用于确定对应人物外貌和服装。

若提供的是俯视示意图，仅补充空间关系；成片机位、环境与光线仍以场景基准和单镜提示词为准。

将人偶替换为对应真人角色，不生成关节人偶、颜色标识、标签、圆圈或箭头。
人物位置沿用人偶站位图，具体表情、对白与动作时序以该镜分镜提示词为准。
```

人偶图是调度参考，不自动改成完整首帧。本例保留厨房基准图原来的锅盖、炒锅等状态；第一场剧本要求揭盖或收锅时，仍需在首帧制作或生成提示词中明确。角色颜色用于识别，不代表服装颜色。
