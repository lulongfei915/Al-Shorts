## 2. 最值得复用的叙事链条

**具体关系与愿望 → 可见的小动作 → 选择的代价 → 时间 / 处境改变 → 同一动作或物件获得新意义。**

“爆款元素” 首先是结构和人物行为，而不是方言、暖黄滤镜、哭泣、白闪或片尾歌的堆叠。以下是样本内的重复机制；是否提升新片表现仍待实际发布验证。



| 机制              | 案例支持                    | 创作转译                         |
| --------------- | ----------------------- | ---------------------------- |
| 动作与异常信息组成开头问题   | 01/04/08/12/13          | 先让观众关心一个具体问题，主体和结尾真正回应       |
| 具体善意有现实成本       | 01/06/07/12/13          | 写少吃、求人、花钱、花时间、放弃机会，而非 “他很善良” |
| 物件 / 动作首尾变义     | 01/04/07/09/10/13       | 日常用途→关系载体→最终选择的证据            |
| 时间压缩与不变习惯       | 01/04/05/06/07/09/12/13 | 同机位或重复动作中改变年龄、物件磨损或听众        |
| 行为改变认知          | 08/09/13                | 不是突然揭秘密，而是新证据让原台词换了含义        |

## 4. 分镜与脚本公式



* **开头**：可见动作＋与预期不符的信息＋一个待回答问题。既可先给 “失去”，也可先给 “已经找到”。悬念可以是原因、代价或关系能否修复。

* **人物场景**：需要→主角选择→付出 / 放弃→对方行为改变。中段每场至少改变一项，避免三次同义照顾。

* **物件回收**：第一次解决生活问题，第二次承载关系压力，第三次证明新的选择。新片改写物件及因果，不只是把包子换成饺子。

* **反转**：初始解释→可回看的异常细节→新证据→主动改变。生硬绝症、突然身世、无根据欺凌不能代替伏笔。

* **镜头组合**：物件建立→空间 / 关系→行动→受者反应；同机位表现时间；相同功能的两个空间表现态度差异。

* **声音**：关键发现前收薄音乐、保留生活声；行动回收后再入音乐。原笔记 RMS 只衡量响度，不是情绪曲线或完播证据。

* **品牌**：前文需求→生活使用→角色反应→关系回收。产品可以早出场，也可以晚出场；删掉品牌名，故事仍成立。

150 秒可先按 10 秒钩子、22 秒关系、55 秒行动升级、23 秒最难处、30 秒回收、10 秒余韵分配，之后按剧情调整。这个预算是本次编剧工具，并非 13 条原片的统计规律。

## 5. 评论给出的反向修正

\*\* 圆满并不弱于遗憾。\*\*07 高赞与后续评论出现 “就怕来刀”“平安住进新房子松了一口气”“终于不是刀人剧情”。因此不把 “虐 / 死亡更容易爆” 写成规则。

\*\* 钩子要有生活依据。\*\*11 最高赞两条均认为同学会抢吃家乡食物，后续也反复质疑 “粽子土” 的冲突。可迁移创业、失败和共同承担；不机械迁移全班羞辱。09 “误怪奶奶” 也有亲历者反对，不能把留守儿童心理一概而论。

\*\* 地方细节要匹配人物。\*\*01 浙江毛师花、12 天津助学人物的川渝口音受到质疑。方言可有表现力，但服从人物地域；不等于通用真实感按钮。

\*\* 观众喜欢内容不等于购买。\*\*02/07/09/10 有广告接受反馈，只能说明部分可见评论认可故事；没有转化数据，不说卖货已被验证。

\*\* 真实素材要与人物对应。\*\*01/12 的本人资料和 13 结尾乡村空镜不同。真实照片也不证明所有戏剧桥段。05 统计数字、06 真假状态、13 原型与钢笔情节需保留核验边界。

## 7. 后续直接这样调用



```
使用 $viral-ai-shortfilm。
这是我的故事：[粘贴故事或剧本]
请改编为约150秒的AI短片剧本，并输出逐镜头分镜。
保留：[必须保留的情节、人物关系或原始结局]
情绪方向：温暖、有回报，不用死亡反转。
如果有品牌：[产品、可确认功能与必要信息]
```

也可以只说 “按 01–13 拉片规律改这个故事，只要剧本”，或 “只拆分镜，不改我的台词”。不必每次填所有参数，缺省会明确合理假设并完成一版。

默认交付一个完整主方案：具体场景、动作、逐句对白、关键声音、总时长；分镜一行一个连续镜头，蒙太奇拆开。末尾简短说明借鉴哪些案例及如何变形，不给空泛爆款分数。

## 8. 校验说明

技能使用标准前置信息并做格式校验；来源索引覆盖 13 个编号、26 个文件；逐一保留可追溯案例时间段；预算示例分别合计 60/90/150/240 秒。检查了陌生题材、真实改编、短品牌片、对白无法压入指定时长的处理规则。

这是规则与资源的静态校验，不代表已通过平台发布验证。后续可把实际成片观看反馈、完播 / 分享数据和失败样本加入，逐步修正哪些机制适合你的账号。
