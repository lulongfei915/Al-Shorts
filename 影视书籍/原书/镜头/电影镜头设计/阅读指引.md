# 《电影镜头设计：从构思到银幕》阅读指引

## 这本书在项目中的作用

它不是用来背术语，而是帮助你把“故事意图”翻译成可拍、可剪、可生成的视觉设计。当前本地资料包括原书 PDF，以及对第三章“故事板”的章节讲解；先用第三章建立方法，再按项目遇到的问题回读原书。

## 推荐顺序

### 第一遍：预读，20 分钟

打开 [原书 PDF](原书/006[电影镜头设计：从构思到银幕（插图第2版）].（美）卡茨.著.井迎兆.译.扫描版.pdf)，浏览目录、章节标题、案例名和插图。只回答三个问题：

- 哪些章节直接解决镜头设计和故事板问题？
- 哪些章节与当前 AI 短片的连续性、调度、剪辑最相关？
- 哪些内容需要回到具体作品才能理解？

### 第二遍：精读第三章

阅读 [第三章核心内容讲解](章节讲解/电影镜头设计-第三章故事板-核心内容讲解.md)，重点掌握：

1. 故事板的两个目的：预先看见并发展意念，以及成为团队共同语言。
2. 先研究、再设计；先确定戏剧任务、不可改变的事实和空间模型。
3. 把故事拆成节拍，再为每个节拍选择视点、调度和摄影机。
4. 静态画面无法独立表达的运动、声音、转场和时间，要用标注补足。
5. 故事板是一次改编，不是把剧本逐句配图。

### 第三遍：带着问题回看片

选一条 `旧梦留声机` 作品，逐段检查：人物姿态是否表达了戏剧信息，镜头是否让观众知道人物在哪，镜头变化是否服务节拍，结尾是否回收了前面埋下的视觉信息。


## 复习与应用

读完第三章后，不要马上继续摘抄。用一条 30-60 秒短片做一次“反向分镜”：先写每个节拍的戏剧任务，再写空间、姿态、视点、运动、声音和剪辑点。最后用成片或原片回看，标出计划与实际的差异。
