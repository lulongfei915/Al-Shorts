### 1. 哪些是原书，哪些是本文的判断

- **原书要义／原书案例：**麦基的概念、主张、假设场景与影片分析。
- **当代辨析：**本文检查这些主张的条件、证据和价值预设，不冒充作者原意。
- **原创教学对照／AI 使用方案：**为此次学习编写的例子、工作表和指令，不是原书案例，也不是当前真实项目的事实。

“较好／较弱”均针对指定叙事目标。诗性影像、音乐影像、实验短片可以有不同目标。本文重点讨论有人物、事件和关系变化的短片。

### 2. 如何判断“是否过时”

| 判断 | 实际含义 | 处理方式 |
|---|---|---|
| 仍适用 | 能帮助解释和修改具体稿件 | 保留，并要求可指认的作品证据 |
| 需要适配 | 在特定篇幅、语言、交付环节或形式中成立 | 写清适用条件，不机械照搬 |
| 年代语境明显 | 与旧产业、社会心态或媒介习惯有关 | 不直接用于预测今天的观众与平台 |
| 论证不足／应纠偏 | 将个人经验说成普遍定律，或混入不成立的群体判断 | 说明为什么不宜接受，不简单统称“过时” |

本文没有开展新的平台数据研究、临床心理学综述或电影史考证。因此，“原书没有证明”不等于“已经证明失效”；AI 应用也不包含特定模型能力承诺、固定留存规律或爆款保证。旧影片仍能演示有效机制，不能只凭年代否定。

## 三、STORY-03｜第 3 章：结构与背景

**原书位置：书 p.69—84／PDF 87—102。重点：p.71—83。**

### 3.1 核心内容：背景是事件成立的条件

**原书要义：**背景包括时代、期限、地点和冲突层面。时代是何时发生；期限是人物经历了多长时间，不能与成片片长混淆；地点是具体空间；冲突层面包括内心、人际、社会机构与环境等力量。（p.71—72）

背景不仅提供服装和景色，还限制什么事可能发生、什么行为合理。幻想也要遵守自己建立的规则，不能前半段不能做的事，结尾为了方便突然能做。（p.73—74）

“小小的、可知的世界”指掌握与当前故事相关的信息，不要求研究世界上的一切。限制可以促使创作者向生活细处发掘，而非不断扩充地域、人物和历史。（p.74—76）

研究分为记忆、想象与事实三个方向。记忆提供体验，想象探索人物生活，事实研究修正盲区；三者需要与创作往复推进。研究最终应长出事件，不能只积累设定。（p.76—80）

最后是创作选择：第一反应可能来自看过的作品。应生成多个可能事件，再依人物、世界与表达新意筛选，而非把每个想法都塞进成片。（p.80—83）

### 3.2 原书示例：同样是邂逅，为什么要列出多个方案

原书设想曼哈顿东区恋人的相遇：先想到酒吧，再尝试路边换轮胎、聚会后在厕所帮助对方等方案。若酒吧确实最符合人物，也可以继续研究同一场所，找出不同的相遇方式。（p.81—82）

其方法不是“换成稀奇地点就原创”，而是**在真实条件下比较多个行动方案**。角色发生什么互动，远比背景从酒吧换成雨巷重要。

原书还用《奇爱博士》说明，核毁灭这样的大题材也可以集中在少数关键空间中讲述。（p.75）可借鉴的是聚焦方法，不应把片中的空间和人数概括当成所有宏大叙事的标准。

### 3.3 原创教学对照：怎样让“公益厨房”摆脱通用布景

**目标：虚构一场使用者在打烊前来取饭的戏，不对应真实机构流程。**

| 版本 | 场面 | 判断 |
|---|---|---|
| 较弱 | 泛化的“爱心厨房”，任何时间都有热饭；主角需要时，老板总能从锅里变出饭菜 | 厨房没有运作限制，主角也不需要作出选择；换成驿站或食堂，故事几乎不变 |
| 较好 | 先建立今日余量已分装、炉火已关、门即将锁上的状态；晚到的人只求热一下自己的冷饭。值班者重新放下钥匙，取回收起的蒸架 | 场所规则造成阻力，人物付出的时间可见；善意体现为具体劳动 |

较好版中的流程也是虚构设定。如果拍真实厨房，应按实际营业、设备和卫生要求重写，不能拿教学例子当调查结果。

### 3.4 观点／理论是否过时

| 原书主张与位置 | 判断 | 今天的处理 |
|---|---|---|
| 世界规则限定事件，p.73—76 | 仍适用 | 检查能力、资源、时间和空间是否前后一致 |
| 记忆、想象、事实研究互相推进，p.76—80 | 仍适用 | AI 可以协助整理问题和材料，事实仍要有来源 |
| 所有陈词滥调只有一个根源：不了解世界，p.70 | 过于绝对 | 熟悉生活的人也会受模板、审美惯性和交付压力影响 |
| 思维阻塞只是没有话可说，p.77—78 | 论证不足 | 可提示补充材料，不能据此解释所有创作困难和心理状态 |
| 精神疾病设定可作为惊悚发现，p.79—80 | 需纠偏 | 相关术语和推论不能当临床知识；不能直接把精神疾病设为危险性的依据 |
| 五比一、十比一等创作备选比例，p.80—83 | 经验方法 | 需要有效差异，不需要凑足数量或固定淘汰率 |

### 3.5 AI 短片适用性与使用方案

**适用性：高。** 现实、职业、公益题材尤其需要；幻想题材也可用来守住设定一致性。

1. 写一张四维背景卡，明确故事时间跨度与成片时长是两件事。
2. 只列会改变行动的规则：何时关门、谁有钥匙、谁能决定、资源有多少。
3. 将材料标成“已核实事实／个人体验／虚构设定／待核实”，不让 AI 混写。
4. 在同样规则下生成几种不同的解决办法，比较人物性格与代价。
5. 将选定规则落实到道具、环境音和动作；无需把背景卡全部解释给观众。

**可交给 AI 的指令：**

> 检查下方短片的时代、期限、地点与冲突层面。逐项引用原稿证据，列出影响行动的世界规则、前后冲突和待核实事实。再提出三个遵守现有规则、但行动机制不同的方案；不要靠新增资源或陌生人解围。没有资料的职业流程标待核实。

**验收：**把场所换成任意一个“温暖空间”后，如果所有动作仍完全一样，说明还需检查背景是否真正参与了故事。

## 四、STORY-04｜第 4 章：结构与类型

**原书位置：书 p.85—108／PDF 103—126。重点：p.93—100；类型演变见 p.101—105。**

### 4.1 核心内容：先知道观众在等什么

**原书要义：**类型常规涉及背景、角色、事件与价值。观众凭已有经验形成预期；创作者既要让观众知道自己进入什么体验，也要在常规中创造变化。（p.86—97）

**常规与陈词滥调不同。** 爱情故事需要建立关系，不等于必须使用反复出现的相遇桥段。常规是创作问题，陈词滥调是对问题的惯常回答。（p.98—99）

精通类型要比较作品：按背景、人物、事件、价值逐项拆解，包括失败作品。混合类型应产生互相支持的新效果；类型也会随着社会现实变化而再造。（p.96—105）

原书清单混合了题材、情节模式、媒介形式和生产传统，比如犯罪、救赎、动画、艺术电影，适合作为作者的操作目录，不是同一分类层级的完整学术体系。（p.87—93）

### 4.2 原书示例：承诺错了，好故事也可能被误读

原书以《麦克谋杀案》说明：如果营销让人期待谋杀谜案，而影片实际重点是女主人公走向独立，观众可能持续等待一个作品根本没有准备兑现的事件。（p.97）这是麦基对作品接受问题的解释，本文未核实它是否构成市场表现的主要原因。

《虎胆龙威》则被用来说明如何翻新“英雄落在反派手中”的常规：背上藏枪，借玩笑分散注意，再改变被控制的局面。（p.99—100）真正值得学的是，**以符合人物的能力回应熟悉困境**，不是复制藏枪桥段。

### 4.3 原创教学对照：情感短片能不能先装成恐怖片

| 版本 | 开头与结尾 | 判断 |
|---|---|---|
| 较弱 | 标题说“半夜敲门的死人”；镜头用血迹与尖叫暗示凶案；结尾却只是父亲来送饭，并无超自然事件 | 主要承诺靠误导建立，结尾的亲情回报没有回应前文承诺 |
| 较好 | 标题提出“他为什么只在门外放饭”；开场是老人放下饭盒又离开，屋内的人始终不回应；后续解释疏离关系，并以一次开门回应 | 疑问始终围绕关系，揭示过去能直接改变当前行动 |

恐怖与温情可以结合。例如亡者只能留下一次声音，就能围绕“如何告别”形成统一规则。问题在于恐怖部分是否真的参与因果，而非只负责骗取开场注意。

### 4.4 观点／理论是否过时

| 原书主张与位置 | 判断 | 今天的处理 |
|---|---|---|
| 研究类型预期，p.93—100 | 仍适用 | 将预期写成一个具体等待：会重逢、会脱险，还是会理解真相 |
| 类型可以混合和演变，p.100—105 | 仍适用 | 可以保留一种主要体验，以另一类型增加压力或表达 |
| 犯罪必须有侦探、动作英雄必须被完全控制，p.94、99 | 需要条件 | 视为作者偏好的常规模型，不能排除其他设计 |
| 喜剧最高常规是无人受伤，p.94—95 | 需改写 | 可用来思考观众感到的安全距离；黑色喜剧与悲喜剧不能用字面标准判断 |
| 关于艺术电影的统一描述，p.93—96 | 审美立场明显 | 不能把不同艺术电影都概括为压抑情感、迎合知识分子 |
| 爱情、婚姻态度与类型兴衰的历史概括，p.101—105 | 年代与文化语境明显 | 不直接用于判断当代中国观众的道德感受和类型需求 |
| 录像带、院线宣传与固定开发周期，p.96—97、106 | 方法可转换 | 改为当前可用的拉片工具与交付周期，不照搬旧媒介路径 |

### 4.5 AI 短片适用性与使用方案

**适用性：高，尤其适合选题与审稿。** 公益是目的、情感是宽泛体验，仍需明确影片通过什么叙事机制交付回报。

1. 写“观众主要等待什么”，再写希望观众最后感到什么。
2. 找若干同类作品，记录它们如何建立、延迟与兑现预期，不只抄标题。
3. 为自己的故事列一项必要情境和几种不同实现办法。
4. 混合类型时说明第二类型怎样改变主要人物的选择。
5. 连同片名、封面、首画面审查承诺；这是原书营销论在短片中的延伸应用。

**可交给 AI 的指令：**

> 从片名、开头、主要冲突和结尾，分别推断这份稿件的类型承诺，引用依据。指出哪项预期得到兑现、哪项被无故抛弃。保留主要体验，给出一个兑现常规的方案和一个有铺垫地改写常规的方案；不要把“意外”等同于“与开头无关”。

**验收：**观众回看结尾时，能否明白“原来开头是在让我等待这件事”？

## 五、STORY-06｜第 6 章：结构与意义

**原书位置：书 p.123—148／PDF 141—166。重点：p.126—138、141—145。**

### 5.1 核心内容：主题需要有结果与原因

**原书要义：**审美情感把情绪与意义组织在同一体验里。前提是激发创作的出发点，如“如果发生某件事”；主控思想是完成故事所表达的核心意义，两者不是一回事。（p.124—127）

主控思想由**价值＋原因**组成：结尾发生了什么重要变化，主要因为什么。例如“亲近恢复”只有价值结果；“亲近恢复，因为父亲开始尊重女儿的决定”才提示选择与后果。（概念依据 p.129—133；此句为本文举例。）

作者并不要求创作一开始就定好口号。他明确提出，可以从意象、人物或事件开始，在高潮出现后回看意义；最初的灵感也可以舍弃。（p.127、132—133）

思想与反思想应通过事件交锋。为了证明自己的观点而把反方写笨、写坏、写成没有合理诉求的人，会削弱作品的说服力。（p.133—138）

理想、悲观与反讽结尾分别处理正面、负面及并存的价值。反讽不是含糊：要说清人物得到什么、失去什么，以及二者的联系。（p.138—145）

### 5.2 原书示例：同样伸张正义，为什么不是同一个主题

原书对比“肮脏的哈里”和“神探可伦坡”：前者在作者的概括中主要凭更强的暴力取胜，后者主要凭更强的智力。只写“正义战胜邪恶”会抹掉二者的重要差别。（p.131—132）

这提示公益短片不能只写“爱可以帮助人”。是资助、尊重、陪伴、专业服务，还是当事人的自主行动改变了局面？不同原因会写出不同故事。

原书还用《走出非洲》等作品说明“失去所执着的东西，却获得自我”的正面反讽。（p.142—144）可借鉴的是所得所失的组织方法，不能由此推出“放弃总比争取高尚”。

### 5.3 原创教学对照：怎样让公益主题摆脱口号

**目标：表现帮助也需要尊重当事人的决定。**

| 版本 | 内容 | 判断 |
|---|---|---|
| 较弱 | 志愿者坚持替老人申请公开捐助；老人立刻感动落泪，片尾写“善意让世界更美好” | 老人的拒绝被消音；只要主角善良，就被安排为正确 |
| 较好 | 老人拒绝公开自己的困境，志愿者认为公开更容易筹款。争执后，志愿者收起准备拍摄的手机，先问老人愿意接受哪一种帮助；老人指向一个自己确实需要的具体任务 | 效率与尊严都有实际诉求；转折来自改变帮助方式，而非把老人写成不识好歹 |

后者的主控思想可以概括为：“合作开始，因为帮助者把决定权还给了当事人。”它只说明这段虚构事件中的因果，不证明所有援助都应采用同一制度。

### 5.4 观点／理论是否过时

| 原书主张与位置 | 判断 | 今天的处理 |
|---|---|---|
| 用价值＋原因梳理意义，p.129—133 | 仍适用 | 很适合审查主题与结尾是否脱节 |
| 由故事发现意义，p.132—133 | 仍适用 | 把主题句当可修改的工作假设 |
| 给反思想足够力量，p.136—138 | 仍适用，但需理解 | 指认真呈现阻力和代价，不要求把事实错误与正确意见等量齐观 |
| 一个完成故事必须熔铸于一句主控思想，p.129—130 | 需要形式条件 | 有助于聚焦，不能据此否定开放、多义和群像作品 |
| 故事以自身事件“证明真理”，p.128—129 | 应区分修辞与证据 | 虚构因果能表达立场，不能自动证明现实社会中的普遍因果 |
| 人天生好战、善恶等量等概括，p.137—141 | 论证不足 | 属作者人性观，不能作为心理学或社会学定律 |
| 反讽最真实、最受喜爱，p.141、145 | 审美偏好／证据不足 | 反讽是一种选择，简洁的温暖结尾也可能准确而有力 |

### 5.5 AI 短片适用性与使用方案

**适用性：很高，公益、纪念和社会议题尤其适合。** 用于减少说教；不应把人物改造成主题证明机器。

1. 先去掉片尾主题字幕，记录作品实际发生的结果。
2. 回溯导致结果的行动，拟一条“价值＋原因”工作句。
3. 写出最有分量的反方理由，检查原稿是否认真呈现。
4. 将一段主题宣讲改为一次有取舍的行动。
5. 对照实际画面，区分“人物想表达的善意”与“影片实际奖励的行为”。

**可交给 AI 的指令：**

> 不参考作者附加的主题说明，仅根据稿件结尾，写出“最终价值＋主要原因”，并列出支撑它的行动证据。检查反方是否被写成傻瓜、主角是否无需付出就总被证明正确。提出一个保留主题、增强反方合理诉求的修改；如果主题句与行动矛盾，先指出矛盾。

**验收：**不靠总结台词，观众是否能理解“这份改变为什么值得、又付出了什么”？

## 六、STORY-09｜第 9 章：幕设计

**原书位置：书 p.237—264／PDF 255—282。重点：p.238—247；篇幅扩大时补 p.247—264。**

### 6.1 核心内容：失败后，旧办法应失去效力

**原书要义：**进展纠葛不是轮流安排倒霉事，而是人物的行动引出反应，使风险与处境变化。越过不归点后，原来同样力度或性质的办法已不能恢复平衡，人物需要更换策略或承担更大代价。（p.238—240）

冲突可在内心、人际、个人外三个层面组织。原书偏爱把几个层面压在同一事件里，以相对有限的人物和场所获得复杂性，而不是不断增生配角、地点。（p.243—247）

幕由重大逆转组织，不是把时长平均分段。作者给出三幕及多幕、次情节、激励事件位置等变体，也承认短篇可用一幕或两幕。（p.247—255）

幕节奏强调避免重复相同情感负荷。次情节可以与主线形成主题对照或回响、为主线铺垫、增加主线困难；若完全自顾自运行，可能把作品撕成两半。（p.256—264）

### 6.2 原书示例：《克莱默夫妇》的一顿早餐

原书分析父亲给儿子做法式烤面包的场景：不会操作厨房、又想维持权威；儿子越来越不安，父亲的动作越来越慌乱。物质操作、父子信任与自我认识在同一动作链中互相影响。（p.245—247）

值得学的不是多写几次烫伤，而是**一次失败同时碰到了不同层面的价值**。厨房无须变成另一场灾难，家庭关系也能被重新认识。

原书还批评《第一死罪》电影版里追凶与照顾病妻的交替缺少可见联系，并对照小说能直接呈现内心冲突的优势。（p.261—263）其教学价值是：交叉出现不等于互相作用。本文不把作者的影片评价当作无争议事实。

### 6.3 原创教学对照：三次求助，怎样不重复

**目标：父亲希望工作繁忙的女儿陪他出门。**

| 版本 | 中段安排 | 判断 |
|---|---|---|
| 较弱 | 父亲问一次，女儿拒绝；换个地方问，再拒绝；下雨了又问，又拒绝 | 场景与天气变化，策略和信息没有改变 |
| 较好 | 父亲先含糊问她有没有空，被拒后独自尝试预约；操作出错，显露自己并不会使用流程。他放下“我一个人都能办”的姿态，直接说明需要陪伴。女儿才知道他不是随便散步 | 第一种回避式请求不再有效；新行动承担了示弱的代价，也改变对方理解 |

女儿不必立即放下一切答应。她也可以提出另一个可行时间；结尾解决的是诚实沟通，而非证明子女应随时牺牲工作。

### 6.4 观点／理论是否过时

| 原书主张与位置 | 判断 | 今天的处理 |
|---|---|---|
| 避免重复已失效的轻量行动，p.238—240 | 仍适用 | 检查失败是否导致信息、资源、关系或策略变化 |
| 用有限场所容纳多个冲突层面，p.243—247 | 仍适用 | 有助于控制 AI 资产数量；短片不必三个层面全齐 |
| 长篇至少三幕与时长分配，p.248—253 | 需要适配 | 不按百分比强切短片；作者也承认独幕、两幕与其他变体 |
| 冲突总量恒定、转移后放大等说法，p.240—243 | 哲学修辞，不是定律 | 不由此推出幸福生活没有叙事价值或必须持续加压 |
| 倒数第二幕必须与最后一幕正负相反，p.256—257 | 过于绝对 | 可检查反差与层次，不必强加绝望低谷；“效果减半”不是测量结论 |
| 对邦德、肥皂剧和意识流的统一判断，p.243—245 | 类型与年代限定 | 不能套用到这些形式的全部作品或后续演变 |

### 6.5 AI 短片适用性与使用方案

**适用性：中段诊断很高，完整多幕模型按片长与复杂度选用。**

1. 将中段写成“尝试→结果→新增限制→下一策略”，每次一行。
2. 找出只是换地点重演同一策略的段落，先合并。
3. 至少让一个关键失败带来持续影响，不能下一场完全复位。
4. 优先挖掘现有人物间的压力；确实需要时再加支线。
5. 支线写明对照、回响、铺垫或制造纠葛的作用；短片没有需要就不加。

**可交给 AI 的指令：**

> 列出主人公每次尝试、结果、此后不再有效的旧办法，以及下一次行动为什么不同。合并只有措辞或地点变化的重复受挫。在不新增灾难、人物和地点的前提下，设计一次使人物必须换策略的变化。不要按固定三幕比例补场景。

**验收：**交换两次失败的顺序，如果几乎不影响故事，检查它们是否只是并列素材。

## 七、STORY-12｜第 12 章：布局谋篇

**原书位置：书 p.335—352／PDF 353—370。重点：p.336—343、351—352。**

### 7.1 核心内容：组织观看过程，而非堆放好场面

**原书要义：**布局谋篇处理场景的取舍、先后与连接。统一性依赖激励事件、欲望和高潮之间的联系；多样性则让场景在基调、行动、关系等方面有所变化，避免同一个音符从头敲到尾。（p.336—337）

需要分清原书的三个术语：

| 术语 | 本章中的用法 | 不宜混淆成 |
|---|---|---|
| 进度 | 组织紧张与松弛、推动观看体验的整体过程 | 平台后台的留存曲线 |
| 节奏 | 本章特别从场景长度及其变化讨论 | 单个镜头的平均长度 |
| 速度 | 场景中动作、对白所表达的活动水平 | 运镜速度或剪切次数 |

依据：p.337—343。高活动水平的场面可能没有新信息；一个人物停下不动，却可能正在改变关键关系。因此“剪得快”不等于“故事推进快”。

进展可以向社会影响横向扩展，也可以向私人关系和内心纵深发展；象征和反讽还可以增加事件的意义层次。它们是不同路径，不是必须集齐的四个阶段。（p.343—351）

场景过渡需要一个连接的“第三要素”，可以来自相似或相反的人物特征、动作、物体、话语、光线、声音、想法。（p.351—352）

### 7.2 原书示例：同一房间如何有变化，两个场景如何有连接

原书用《十二怒汉》讨论“法式场景”：人物的加入、退出和组合改变关系，即使空间没有更换，戏剧动力也可以更新。（p.340—341）可借鉴的是**改变谁与谁形成压力**，而不是反复生成同一桌人的不同景别。

过渡例子包括从波浪声连接到呼吸起伏、从热烈闲聊切到冷漠沉默。连接可以顺势，也可以借反差表达关系。（p.352）但画面相似只能建立联想，不能自动证明两个事件有因果。

### 7.3 原创教学对照：一直悲伤为什么反而麻木

**目标：表现一个家庭整理逝者遗物时的关系变化。**

| 版本 | 场景顺序 | 判断 |
|---|---|---|
| 较弱 | 看照片哭→摸旧衣哭→看空椅哭→旁白说想念→再次哭 | 物件变了，情感功能几乎不变；没有不同的认识和行动 |
| 较好 | 两人争执旧收音机该不该扔→意外转出走调的旧歌，短暂发笑→一人准备拔掉电池，另一人说先留着→收音机被挪到仍有人使用的桌上 | 争执、松弛、犹豫和共同决定形成层次；物件的用途发生变化 |

这不是要求丧亲故事必须插笑话。笑来自具体记忆与关系；不合人物的喜剧插曲同样会打断情绪。

### 7.4 观点／理论是否过时

| 原书主张与位置 | 判断 | 今天的处理 |
|---|---|---|
| 统一性中保留多样性，p.336—339 | 仍适用 | 统一的是叙事任务，不要求每场同一种情绪 |
| 社会进展与个人进展，p.343—345 | 仍适用 | 小体量短片通常更适合先挖关系，不必扩大为社会事件 |
| 用共有或相反要素过渡，p.351—352 | 仍适用 | 制作前就规划声画连接，避免素材完成后才补救 |
| 长片平均场景长度、剧本页数与时长关系，p.340 | 需要适配 | 英文标准剧本的经验不能直接换成中文页数、镜头数或模型片段数 |
| 几分钟就能耗尽空间的视觉表现力，p.340 | 过于绝对 | 是否乏味还取决于调度、表演、信息与观看目的 |
| 激励事件使高潮“必须发生”，p.336 | 应理解为结构联系 | 不是开头能唯一预测结尾，而是结尾回答由开头引出的核心问题 |
| 象征只在未被意识到时生效，p.346 | 论证不足 | 可以避免直白解释，但观众识别象征不等于失去情感 |

### 7.5 AI 短片适用性与使用方案

**适用性：很高，尤其适合事件稿到分镜、素材到粗剪的阶段。**

1. 给每场写一句功能：提出问题、尝试、改变关系、揭示、决定或收束。
2. 记录该场增加的信息与改变的处境，识别连续重复。
3. 分开检查情节推进、场景长度、动作密度和镜头剪切，不用一个“快慢”包办。
4. 为相邻场景设计连接要素，写明它传递的是时间、因果、联想还是反差。
5. 把必要的开头与结尾状态列入素材需求；保留让关键反应被看清的时间。

**可交给 AI 的指令：**

> 按场列出叙事功能、新增信息、关系变化、紧张或松弛状态。找出功能重复和无连接的两处。在不添加新剧情的前提下建议删并或调序；为相邻场景各提出一个动作、物件或声音过渡，并说明连接含义。不要用加快剪辑替代缺失的事件。

**验收：**只读场景功能表，能否感到事情在改变？只听声音、或只看静音画面时，又分别能理解哪些连接？不要求两条通道各自交代全部内容。

## 八、STORY-14｜第 14 章：反面人物塑造原理

**原书位置：书 p.369—386／PDF 387—404。重点：p.370—377、384—385；争议段落 p.381、383—384 需批判阅读。**

### 8.1 核心内容：塑造与欲望相遇的阻力

**原书要义：**这里的“反面人物”实际上指对抗力量，不只是坏人。人物内心、亲近关系、社会机构和物质环境都可能阻挡欲望。阻力的强度与复杂性，影响主人公需要展示多少智慧、意志和能力。（p.370—371）

作者用一组价值位置检查负面力量是否只在表面打转：正面、相反、矛盾、负面之负面。最后一项强调的不只是“更惨”，而是负面情境发生质变。（p.372—377）

| 原书价值轴 | 正面 | 相反 | 矛盾 | 负面之负面 |
|---|---|---|---|---|
| 正义 | 正义 | 不公平 | 非正义 | 专制 |
| 爱，第二种变体 | 爱 | 冷漠 | 恨 | 以爱为面具的恨 |
| 真理 | 真理 | 善意谎言、半真半假 | 谎言 | 自欺 |

表据 p.372—376；图示已回看扫描页。此处的“相反／矛盾”是作者的分析词汇，不是统一的逻辑学或心理学分类。现实中的歧视和不公平也可能违法，不能按表格机械划界。

“以爱为面具的恨”不能直接改写为“所有不恰当的关心都出于恨”。在具体人物身上，还需区分关心、恐惧、控制、羞耻、敌意等不同动机。

### 8.2 原书示例：《失踪》里负面力量如何发生质变

原书分析《失踪》：父亲先遇到敷衍、半真半假的信息，再得知儿子遭杀害，最后面对无法借正常程序申诉的专制环境。阻力从个别办事不公，发展为救济机制本身被夺走。（p.374）

这个例子说明，**让人物陷入更深困境，可以改变规则和权力关系，而非只增加伤亡人数**。但它不要求一条家庭短片也上升到制度崩溃。

原书的《超人》例子则把肉体能力的限制推进为亲情戒律与爱人生命之间的选择。（p.371）其中时光倒流是该幻想设计的一部分，不能据此给现实片安排一个临时新增的万能解决能力。

### 8.3 原创教学对照：比“恶人刁难”更具体的阻力

**目标：年轻志愿者希望老人接受一份免费餐食。**

| 版本 | 阻力与解决 | 判断 |
|---|---|---|
| 较弱 | 老人无缘无故骂人；志愿者说自己很善良；老人突然醒悟，向他道谢 | 反对者只是衬托主角，阻力没有具体意义 |
| 较好 | 老人看到排队的人将被逐一拍照，转身离开；志愿者起初只想着完成记录，挡住他的路；后来收起镜头，提供不进入画面的领取办法，由老人决定是否回来 | “被帮助”与“被展示”形成实际冲突；主角也参与制造阻力，因此必须改变做法 |

这场戏不需要把老人诊断成“自卑”，也不必揭露他更多苦难。阻力来自对自主、尊严与工作任务的不同理解。具体机构能否采用该流程，仍须按事实与项目条件处理。

### 8.4 观点／理论是否过时

| 原书主张与位置 | 判断 | 今天的处理 |
|---|---|---|
| 对抗力量不限于坏人，p.370 | 仍适用 | 温柔短片也可有阻力，不必硬加反派 |
| 寻找负面的质变，p.372—377 | 有效诊断工具 | 比较“更难”与“原有应对机制失效”的区别 |
| 不到负面之负面就不能伟大，p.384—385 | 过于绝对 | 微小修复、日常观察、含蓄和解不必走到黑暗极限 |
| 所有弱故事都因对抗力量不足，p.385 | 论证不足 | 目标不清、信息失衡、结尾无因果等也会让故事变弱 |
| 将多数自杀理解为缺乏生的勇气，p.381 | 应拒绝作为现实判断 | 把复杂心理与处境压缩成道德标签，不能用于解释现实人物或设计公益叙事立场 |
| 以“自然／不自然、认可／不认可”混列性行为，p.383—384 | 分类和价值前提需纠偏 | 性取向、性别表达、双方自愿的成人行为，与强迫、剥削及侵害不能混同；具体判断应看同意、伤害与权力关系 |

最后两项已核看扫描页，不能归咎于 OCR 误读。保留戏剧分析工具，并不意味着要接受作者的全部心理解释与价值排序。

### 8.5 AI 短片适用性与使用方案

**适用性：高，但最需要防止被误用为“加惨教程”。**

1. 写出人物本次欲望，再列内心、人际、制度或环境阻力；允许只有一两层。
2. 每项阻力说明怎样妨碍行动，不只填写“冷漠社会”“固执老人”。
3. 给对方一项自己的诉求或限制，使冲突有现实来源。
4. 若故事过轻，先加强选择的代价；不先加死亡、疾病和事故。
5. 用价值表探索备选，不强制把所有负面位置写进成片。

**可交给 AI 的指令：**

> 根据人物欲望，列出原稿中实际存在的对抗力量及证据，区分内心、人际与外部条件。指出哪项阻力只靠标签成立，哪项确实迫使人物改变行动。提出一个通过关系、规则或选择代价增强压力的方案；不要把疾病、贫困、性取向或创伤本身当作恶的证据，不自动追加灾难。

**验收：**对抗一旦消失，主角是否不需要再改变做法就能成功？如果是，这项阻力是否真的把人物推到了选择面前？

## 九、STORY-15｜第 15 章：解说

**原书位置：书 p.387—402／PDF 405—420。重点：p.388—395；使用闪回、旁白时补 p.396—401。**

### 9.1 核心内容：“解说”是必要信息，不等于旁白

**原书要义：**解说包括观众为了理解事件所需的世界、经历、关系与人物信息。它可以通过对白、动作、道具、闪回和画外音传递。（p.388）

戏剧化的解说同时做两件事：人物为了眼前目标行动，观众从行动中获得信息。将解说变成“弹药”，意在让既有事实参与当下博弈，不要求每个人都吵架。（p.388—389）

作者主张按需释放信息：不用把观众可以推断的事实再讲一遍；先让观众产生问题，再在需要的位置补上事实。重要幕后事实可以改变人物和观众对当前事件的理解。（p.389—396）

闪回应有当前作用，不能只因作者舍不得过去的材料就插入。梦境、蒙太奇、画外音也要检查其功能，不能靠形式装饰遮掩信息堆积。（p.396—401）

### 9.2 原书示例：朋友关系如何从介绍变成行动

原书先给出一种僵硬对白：两个老朋友互相交代早已知道的二十年交情。随后改写为一人利用对方的旧经历批评他如今的状态；人物在施压，观众顺带知道他们的关系与过去。（p.388—389）

重点是**此刻为什么要说**。熟人也会回顾往事，但应存在安慰、责备、试探、讨好等当前目的。

原书还以《唐人街》和《帝国反击战》的亲缘揭示说明，幕后信息可以转折行动；并用《卡萨布兰卡》的巴黎闪回说明，先建立观众的疑问，过去的场景才有进入当前叙事的理由。（p.391、395—398）

### 9.3 原创教学对照：对白、旁白和闪回怎样各尽其用

| 问题 | 较弱版本 | 较好版本及机制 |
|---|---|---|
| 交代多年习惯 | 母亲说：“你从小不吃葱，我每次都替你挑掉。” | 儿子刚抬筷，母亲已经把葱拨开；儿子这次挡住她的手，说现在吃了。旧习惯与眼前变化同时可见 |
| 交代长期等待 | 画面是空椅与窗户，旁白连续重复“她等了很久，非常想念” | 画面表现她把第二副碗筷重新收起；旁白补充画面难以直接表达的时间跨度或叙述者后来才知道的事实 |
| 插入往事 | 正在争执，忽然播放一整段温暖童年，没有改变争执 | 先出现对旧伤痕的误解，再用必要的短闪回提供新依据，回到当下后人物改变了责备方式 |

以上都是原创教学示例。“拨葱”若已经成为当前作品里的惯用模板，也需继续寻找更贴合人物的动作。

**旁白的实际检验：**

- 画面已经明确表达，声音只是复述：优先删减或改写。
- 声音提供必要时间压缩、视点、反讽或语言风格：可以保留。
- 旁白宣布理解、和解，画面没有对应行动：先补戏，或明确作品采用的是叙述体。
- 删除旁白就完全无法理解：先判断它是不是有意的主叙述通道，不能据此直接判失败。

### 9.4 观点／理论是否过时

| 原书主张与位置 | 判断 | 今天的处理 |
|---|---|---|
| 人物为眼前目标使用信息，p.388—389 | 仍适用 | 是修复“解释型对白”的直接办法 |
| 按需披露，而非开头塞满，p.389—395 | 仍适用 | 仍要先给够理解行动所需的基本信息 |
| 重要秘密尽量留到后面，p.390—391 | 需要条件 | 提前公开秘密也能创造担忧；信息位置取决于预期体验 |
| 闪回要回应已建立的问题，p.396—398 | 高价值建议，非唯一合法用法 | 也可用联想或诗性方式组织，但要有明确形式目的 |
| 梦境、蒙太奇多数是懒惰，p.398—399 | 审美偏向明显 | 时间压缩、记忆组织、主观经验均可构成独立表达任务 |
| 画外音会使电影退化，p.399—401 | 不宜接受为普遍结论 | 判断其信息、视点和声画关系，不按出现次数判优劣 |
| 陌生人倾诉只在加州、弱势人物无可失等说法，p.390、393 | 应纠偏 | 前者是地域刻板印象；后者忽略尊严、关系、习惯、自主等非财产价值 |

### 9.5 AI 短片适用性与使用方案

**适用性：很高。** AI 情感短片常使用跨年代叙述与旁白，尤其需要做信息分工。

1. 列出观众理解故事必需的事实，不先写所有人物传记。
2. 给每项信息一个“最晚必须知道的位置”。
3. 决定由行动、对白、道具、旁白或闪回承担；避免各通道重复交代。
4. 每段对白写出当前目的，每段旁白写出新增内容或语气作用。
5. 有声看一次，再静音诊断画面承担了什么；静音检查用于识别分工，不是要求作品无声也能完整成立。

**可交给 AI 的指令：**

> 提取观众必须知道的事实，标出首次提供的位置、承载通道和缺失后果。逐段检查对白为何在此刻说、旁白增加了什么、闪回怎样改变当下。只对重复或无功能的信息提出删改；保留有明确时间压缩、视点和反讽作用的声音。不要把“展示”简化为不用语言。

**验收：**观众能跟上人物为何行动，又仍然有想知道的事；人物没有只为观众补课而暂停生活。

## 十、STORY-16｜第 16 章：问题和解决方法

**原书位置：书 p.403—434／PDF 421—452。本章宜按问题检索，但本次读取了全章。**

### 10.1 核心内容：八类故障，要分开诊断

| 问题 | 原书方法的转述 | 书页／PDF 页序 |
|---|---|---|
| 兴趣 | 同时组织好奇与关心，并安排观众和人物的信息关系 | p.404—413／422—431 |
| 惊奇 | 区分能带来新理解的揭示，与仅仅吓人一下的打断 | p.414—415／432—433 |
| 巧合 | 让巧合进入后逐渐参与故事，警惕用它代替人物解决核心问题 | p.415—418／433—436 |
| 喜剧 | 从人物行动的预期与荒诞结果中创造可笑的转折 | p.418—422／436—440 |
| 主观视点 | 区分主观镜头、场景的体验中心与整个故事的叙述重心 | p.422—425／440—443 |
| 改编 | 不只换写法，而要为内心冲突重新寻找银幕表达 | p.425—431／443—449 |
| 戏剧腔 | 强烈行为若缺少足够动机，会显得刻意煽情 | p.431／449 |
| 漏洞 | 检查原因和结果的缺口，避免笨拙地加一场说明戏 | p.432—434／450—452 |

本章最值得掌握的信息关系是：

| 麦基使用的术语 | 对某项关键信息的关系 | 主要观看问题 |
|---|---|---|
| 神秘 | 观众比相关人物知道得少 | 他知道什么？先前究竟发生了什么？ |
| 悬念 | 观众与相关人物大致同步获知 | 他们知道局面如此，会怎么办？结果如何？ |
| 戏剧反讽 | 观众比相关人物知道得多 | 他何时发现？发现后或尚未发现时会怎样？ |

据 p.408—413。**这是一套作者术语，不是对所有语境的唯一命名。** 日常影视讨论也会把“观众知道炸弹、人物不知道”产生的紧张叫悬念；不能因为词义不同就认为方法相互否定。

更不能比较“观众与所有角色知道的全部信息总量”。原书的开放神秘案例里，观众知道凶手，却仍不知道侦探将如何找出漏洞。应针对一个事实、一个人物、一个时刻比较；一部片可以不断转换关系。

### 10.2 原书示例：同一走廊，信息分配改变了什么

原书设想女侦探接近持斧凶手：不让观众知道位置，会产生搜寻；让双方都知道对方在门两侧，焦点变成谁能取胜；先给观众看门后的凶手，而侦探还不知道，会产生替她担忧的体验。（p.412—413）

如果最后突然说拿斧头的只是她的伴侣，先前的危险暗示没有合理依据，那就可能沦为虚假神秘。重要的是信息组织是否诚实，不是结尾能否让人猜不到。

巧合部分，原书以寻找恋人时偶遇房产代理商为例：直接得到地址、代理商随后消失，像便利工具；若代理商进入关系并造成新纠葛，偶遇就开始承担后续意义。（p.415—416）不必照搬该例的关系模式，保留“偶然事件需要后续作用”的方法即可。

### 10.3 原创教学对照：反转、巧合、视点和动机

| 故障 | 较弱版本 | 较好版本及原因 |
|---|---|---|
| 不公平反转 | 前半段清楚展示父亲与女儿在同一桌互动；结尾突然说女儿从未到场，全是回忆，却没有主观叙述线索 | 先建立父亲的回忆视点；同一空座位、声音来源和时空转换留有依据，揭示后重新理解先前画面 |
| 巧合救场 | 主角筹不到钱，结尾陌生富商突然出现支付全部费用 | 开头建立现有互助约定；主角主动决定求助并承担难以启齿的代价，结果来自已铺垫的关系和行动 |
| 视点失控 | 一直跟随孩子，却突然进入所有成人的私下谈话，只为补齐解释 | 保持孩子的有限理解；若转向成人视点，明确转换，并让它提供新的体验，而非补作者遗漏 |
| 戏剧腔 | 一句普通误会，人物立即摔东西、跪地痛哭，随后迅速和好 | 建立正在失去的重要东西、误会为何触发旧冲突，再让行动与人物承压方式一致；必要时缩小动作 |
| 喜剧目标错位 | 用跌倒、病痛或贫困本身制造笑点，然后强行转公益感动 | 笑点来自帮助者的自作聪明被现实纠正，当事人保有能动性；随后关系改变由行动承接 |

第一行并非规定所有回忆片都要提前明示。可保留误认，但不能凭空否定此前作为客观事实明确展示的行动关系。第三行也不要求全片必须单一视点。

### 10.4 观点／理论是否过时

| 原书主张与位置 | 判断 | 今天的处理 |
|---|---|---|
| 好奇与关心、信息关系，p.404—413 | 仍适用 | 针对具体事实制作信息差表，比空泛地要求“多反转”有效 |
| 真实惊奇带来新理解，p.414—415 | 仍适用 | 检查揭示后人物或事件意义改变了什么 |
| 过中点不再用巧合，p.416—418 | 需放宽 | 中点不是通用禁线；重点是偶然性是否代替核心抉择，并符合既定形式 |
| 喜剧能容纳巧合与游离笑料，p.420—422 | 类型条件明确 | 纯喜剧可这样组织，公益情感片应另查语气与人物尊严 |
| 所有观众都必须寻找“善之中心”，p.405—408 | 论证不足 | 理解、关注、移情和道德赞同并非一回事，不必把复杂人物洗白 |
| 正剧与喜剧、不同国家幽默能力的概括，p.418—420 | 过度概括／刻板印象 | 不把作家性格、国别和幽默能力绑定 |
| 小说、戏剧、电影各有固定优势，纯文学难以改编，p.425—430 | 可作倾向提示，不能视为禁令 | 视听主观化、表演与声音都可重新组织内心经验；改编需要另行设计 |
| 观众也许不会注意漏洞，p.432—434 | 不宜作为主要策略 | 可以保留有意的未知，核心因果缺口则应优先修复；一句自嘲不能自动使矛盾合理 |

“戏剧腔来自动机不足”（p.431）是有用的第一问，但表演风格、台词、配乐和镜头强调也会影响感受，不能只加一段悲惨身世就认为已修复。

### 10.5 AI 短片适用性与使用方案

**适用性：很高，适合作为综合审稿工具。** 对反转型故事，先查信息与因果，再考虑镜头刺激。

1. 只选三到五项关键信息，逐场写观众、主角及相关配角何时知道。
2. 先确定希望观众追问事实、担心结果，还是等待人物发现。
3. 检查每次揭示的来源：当事人告知、可见证据，还是作者突然宣布。
4. 给巧合和救援画出前因：是否有联系渠道、到场条件和主动行动。
5. 改编时先提取事件，再处理内心经验；真实故事另将已证实事实与虚构重组标开，不能把“再创造”当作捏造真实人物经历的依据。
6. 用粗略分镜或粗剪验证：线索是否看得清、信息是否来得及被理解。提示词写了伏笔，不代表生成画面已经呈现伏笔。

**可交给 AI 的指令：**

> 对每项关键事实分别列出观众、主角与相关人物的获知时点及来源。检查虚假神秘、无铺垫反转、巧合代替决定、视点突然跳转、行为动机不足、核心因果缺口。每个问题引用原稿证据并给最小修复；未知处明确标出，不凭空补设定。优先报告最影响理解的三项。

**验收：**结尾揭晓后，观众回看能找到依据；作品保留的未知不会妨碍理解当前行动，偶然事件也没有替人物承担全部选择。

## 十一、STORY-17｜第 17 章：人物

**原书位置：书 p.435—450／PDF 453—468。重点：p.437—447。**

### 11.1 核心内容：维度来自连贯矛盾，不来自技能数量

**原书要义：**人物是经过选择和组织的艺术形象，不等于一份现实人的完整档案。欲望使人物行动，动机解释欲望的来处；动机可能有多重来源，不应以单次童年创伤概括全部行为。（p.437—439）

本章的“人物维”指连贯的矛盾：可能是深层性格之间，也可能是外在表现与压力选择之间。矛盾需要反复在情境中显现，不能前面一直善良，突然踢猫就算复杂。（p.440—441）

人物群体通过关系引出彼此不同的一面；配角和小角色的强调程度也会形成观众预期。原书以主人公为中心组织全体人物，强调小角色不要制造作品不准备兑现的期待。（p.441—444）

喜剧人物可以由自己看不见的执念驱动。写作还应为表演保留空间，理解所有角色如何为自己辩护，并结合观察和自省构思。（p.444—450）

### 11.2 原书示例：技能清单为什么不等于人物深度

原书批评一位制片人把出狱、懂投资、跳舞、空手道、萨克斯管等特征堆给“杰西”，就认为他是立体人物。这些特征尚未形成有意义的选择关系。麦克白的野心与负疚，才是作者认为能够持续产生行动的矛盾。（p.440）

小角色部分，原书设想一位显得热心却欺骗乘客的出租车司机：这样的外表与行为反差，可能让人期待他之后还有作用。（p.442—444）值得学的是控制叙事强调，不是认定所有有趣路人都必须再次出场。

### 11.3 原创教学对照：把“坚强母亲”改成有矛盾的人

| 版本 | 人物设定与行为 | 判断 |
|---|---|---|
| 较弱 | 善良、坚强、会做饭、爱孩子、命运坎坷、年轻时会唱歌 | 都是属性或履历，尚不知道她遇到冲突会如何选择 |
| 较好 | 她不肯接受孩子给的钱，怕自己成为负担；却又反复确认孩子到家的时间。孩子提出今天不转钱、只陪她一起修门锁，她先推说不用，最后把工具盒推到两人之间 | 自主需求与亲近需求同时存在；拒绝和接受有具体对象，矛盾通过行动被认识 |

可把矛盾写成：“她希望自己不需要别人，也希望别人愿意留下。”这是一种戏剧工作假设，不是对所有老年母亲的心理诊断。

**配角也要有目的：**孩子不应只是等着被母亲感动。他可以希望母亲直接说需要什么，避免双方用金钱和拒绝代替沟通。这使两人的互动不只是主角表演的陪衬。

### 11.4 观点／理论是否过时

| 原书主张与位置 | 判断 | 今天的处理 |
|---|---|---|
| 维度是连贯矛盾，p.440—441 | 仍适用 | 检查矛盾是否在同一人物的多次选择中成立 |
| 不把人物缩成单一创伤原因，p.438—439 | 仍适用 | 保留多重动机与解释空间，不自动补一段受虐史 |
| 主人公必须最多维，其他人物围着他转，p.441—444 | 有形式边界 | 可服务单主角片，群像、双主角与刻意转移关注的作品可另作组织 |
| 配角出现反差后就必须再次使用，p.443—444 | 过于绝对 | 是否需要回收取决于强调程度、片长及其他功能 |
| 从中立视点就不会移情，参见本书 p.424；本章强调中心人物 | 不能机械理解 | 观察距离并不自动取消情感，调度与上下文也在起作用 |
| 为演员留空间，p.446—447 | 原理仍有效，AI 工作方式需适配 | 不堆装饰性微表情，但要明确关键行为、目标和节拍 |
| 自问“如果我是他”就总能得到正确答案，p.449—450 | 论证不足 | 自省只能生成假设，还要用背景、调查和人物差异修正 |
| 以角色复杂度解释《银翼杀手》接受问题，p.441 | 单因解释不足 | 可讨论关注重心，不把它当已核实的市场因果 |

### 11.5 AI 短片适用性与使用方案

**适用性：高，最适合压缩 AI 人物小传并修复工具化配角。**

1. 人物卡只保留本次事件相关的欲望、担忧、一组矛盾和行动证据。
2. 为矛盾两端各设计一个可观察行为，说明它们为何出自同一人物。
3. 给每个重要配角自己的目标，检查他为何留下、拒绝或改变。
4. 把表演说明写成“想做什么、受什么阻挡、最后做什么”，再增加必要动作。
5. 试生成时优先验证关键行为能否读懂，不用密集微表情弥补缺少选择。

**可交给 AI 的指令：**

> 将人物小传压缩为：当前欲望、担忧、连贯矛盾、原稿行为证据。区分特征堆积、真正矛盾与无动机反常。给重要配角写出自己的目标。设计一组在现有情境下揭示矛盾的动作／反应，不添加童年创伤或诊断，不把复杂等同于忽好忽坏。

**验收：**删掉“善良、坚强、孤独”等评价后，人物的行动是否仍让人感到他有不同方向的牵引？

## 十二、STORY-18｜第 18 章：文本

**原书位置：书 p.451—476／PDF 469—494。重点：p.452—465、466—475。进入 AI 分镜与制作前优先读。**

### 12.1 核心内容：让文字变成可体验的声画

**原书要义一：对白是选择过的行动，不是日常谈话的逐字记录。** 它需要简约、方向和目的，听起来又应符合人物。长段话也应有动作／反应与策略变化，不是把同一情绪读满一分钟。（p.452—457）

作者提倡先尝试无言表达，语言在必要时进入。可取的是寻找其他表达途径，而非认定语言天生低于画面。（p.457—458）

**原书要义二：描写应让人想象银幕正在发生什么。** 泛化的“他等了很久”需要转为时间痕迹或行为；具体名词与动作比一串抽象形容词更容易建立画面。明喻、暗喻能否使用，要看能否形成可见或可闻的效果。（p.459—462）

原书反对在阅读剧本中堆积摄影、剪辑注释，但也保留信息理解所必需的插入、主观角度等说明，并示范以段落暗示观看顺序。（p.462—465）这不是对所有制作文件的镜头禁令。

**原书要义三：形象系统来自重复中的变化。** 一个类别的声画形象贯穿作品，随事件积累含义。外部形象法借用既有象征，内部形象法在作品中建立独有联系。诗化的目的在于强化表达，不只是让镜头好看。（p.466—475）

片名也参与定位，最好与人物、情境、主题或类型有实质关联。它与第 4 章的类型承诺相连。（p.475—476）

### 12.2 原书示例：字条、水与变化中的含义

**字条场景：**杰克进屋，发现妻子离开的字条。若观众不知道内容，就需要让观众获得这项信息；若此前已经知道，则可把重点放在他的反应。后来书中以提包、古董椅、婚戒和字条等行为单元示范观看顺序。（p.463—465）

它说明：镜头先看什么，应由信息与动作决定，而不是每句描写都默认一个“电影感特写”。

**《恶魔》的水：**原书追踪泥水、雨、饮用液体、泳池、浴缸和滴水声，说明“水”如何在本片中与恐惧和死亡相连，而不只是沿用纯洁、生命等习惯象征。（p.468—471）

可借鉴的是**在情境中积累含义**，不必把每部温情片的水都拍成恐怖，也不用照单全收作者对各种象征的普遍意义概括。

### 12.3 原创教学对照：抽象句、金句和意象怎样改

| 问题 | 较弱版本 | 较好版本及原因 |
|---|---|---|
| 心理不可见 | “她终于放下了戒备，愿意接受孩子的关心。” | 她把一直攥着的工具盒放到两人中间，拨开卡扣，把螺丝刀转向孩子。动作给出合作的入口，需由前文关系支持其意义 |
| 台词同声 | 所有人都说“爱是岁月深处不灭的灯火” | 母亲仍嘴硬说“别把螺丝弄丢了”，孩子不辩解，接过工具；语言在维持各自习惯，行动改变关系 |
| 单镜动作过载 | 同时开箱、抹泪、递工具、拥抱、转身，又要求长距离运镜 | 先让观众看清工具盒被放下，再拍接受或未接受的反应；分段由行为意义决定，生成可行性另行测试 |
| 意象装饰 | 每场都加落叶、烛火、白鸟，旁白逐一解释象征 | 只保留本来就参与生活的门锁与钥匙：先是卡住的阻隔，后来是两人一起修好的入口；事件改变物件的关系含义 |
| 片名游离 | 泛化的《永恒的爱》，片中没有相关的具体命题 | 工作片名可用《门还没修好》，先指向真实行动；最终是否选用，再检查语气、歧义与类型承诺 |

这些都是教学改写，不能仅凭一个递工具动作宣告多年关系完全和解。声画能表达多大变化，需要前文与后果共同支撑。

### 12.4 观点／理论是否过时

| 原书主张与位置 | 判断 | 今天的处理 |
|---|---|---|
| 对白简约、有方向、有目的，p.452—457 | 仍适用 | 允许沉默、重复和口语停顿，只要它们在关系中有功能 |
| 具体名词、动作与可拍摄描写，p.459—465 | 仍适用 | 对 AI 尤其有帮助，但“写得具体”仍不保证生成准确 |
| 形象系统的重复与变体，p.466—475 | 仍适用 | 选择可控制、与行动有关的少数形象；不是多塞符号 |
| 视觉八成、听觉两成等比例，p.453—455 | 没有给出足够证据，不宜当定律 | 对白、声音与音乐的重要性取决于作品；不据此压低声音预算 |
| 十几秒就耗尽脸部表现力、理解一半依赖唇读，p.454 | 过度概括 | 不据此禁止长镜头、独白或画外讲话，具体看表演和信息变化 |
| 禁用某些英语系词、押韵与句法要求，p.454、457、460—461 | 语言与文体限定 | 中文看听觉顺畅、含义清楚与人物口吻，不逐词移植 |
| 删除所有镜头／剪辑说明，p.462—465 | 交付语境限定 | 阅读剧本可以精简；导演分镜与 AI 制作任务需要必要控制信息 |
| 象征一旦被识别就无效，p.468、473—474 | 论证不足 | 避免说明性重复，不以“观众绝不能发现”为硬标准 |
| 漂亮画面只能表达漂亮主题，p.466 | 过于绝对 | 声画与情境可以形成反讽；关键是形式是否准确参与表达 |

### 12.5 AI 短片适用性与使用方案

**适用性：很高，是本轮最直接连接制作的一章。** 应把文稿分为不同用途，避免要求一份文字同时承担全部任务。

| 层级 | 应写清什么 | 示例 |
|---|---|---|
| 创作分析 | 欲望、担忧、潜文本与转折 | 她想保有自主，也愿意让孩子参与 |
| 声画剧本 | 可见动作、可闻声音、台词与反应 | 她把工具盒放下，打开卡扣，推到两人中间 |
| 导演分镜 | 观看顺序、信息重点、景别、站位和连接 | 先交代两人距离，再让工具盒进入共同空间，最后看对方反应 |
| AI 制作任务 | 已确定资产、片段起止状态、关键行为、连续性与验收条件 | 道具盒位置和开启状态匹配；关键递接行为清楚；必要声音可后期完成 |

上表为本文应用，不是原书给出的 AI 流程。镜头参数和提示词结构应由实际制作工具决定。

执行步骤：

1. 标出抽象心理句，决定用行为、声音、语言还是有意的主观影像表达。
2. 给每项关键表达保留前因和反应；不只生成漂亮动作，漏掉接受或拒绝。
3. 把多步行为拆成观众能理解、当前工具能控制的片段；不机械规定每片段只能一个动作。
4. 建立人物、场景、道具参考，记录道具位置、状态、朝向和前后关系。
5. 选择少数形象，列出每次出现时的用途与含义变化。声音也能形成系统。
6. 先试最关系理解的镜头。若关键文字、手部接触、口型或细微表情不可靠，换表达路径或后期补足，再评估是否保留设计。
7. 分别检查成片的故事事实、视听可读性和资产连续性。视觉无穿帮不代表叙事已成立。

**可交给 AI 的指令：**

> 把以下剧本逐场转换为可见动作、可闻声音、台词和反应。保留原有情节与含义，抽象心理不能直接作为画面已表达的证据。先给声画剧本，再另列必要的分镜信息和制作难点。对关键道具列出起止状态、前后连接与验收条件；为每处高难表达提供一个不改变核心意义的替代方案。

**验收：**把人物心理说明藏起来，单看拟定的声画内容，是否仍有足够证据支持希望观众理解的变化？

## 十三、STORY-19｜第 19 章：作家的创造方法

**原书位置：书 p.477—486／PDF 495—504。重点：全章。**

### 13.1 核心内容：先让修改发生在成本较低的层面

**原书要义：**作者批评一种循环：先写满对白和场面，再为保住喜欢的段落寻找故事；反馈指出开头、中间、结尾不对，修改却只是在这些场面外面换包装。（p.478—480）

他偏好的“从里到外”先做步骤大纲，再展开处理台本，最后写银幕剧本。步骤大纲记录各场发生了什么、怎样转折；它能使大幅删改相对容易，也便于从结尾回头检查铺垫。（p.480—483）

处理台本进一步探索动作、反应和潜文本；最后才把这些转成银幕描写与人物语言。对白阶段若暴露结构问题，还应回到大纲或处理台本修改，不能只在用词上修补。（p.483—486）

**一处重要区别：**第 19 章的内部处理台本允许写出人物如何理解局面、为何流泪；第 18 章要求面向银幕的描写回答看见／听见什么。两者服务于不同环节，并不矛盾。AI 分析稿里的心理解释，仍须进一步变成观众能够体验的内容。

### 13.2 原书示例：同样读字条、坐下哭，含义可能相反

原书先写杰克发现妻子离开后坐下哭泣，再在处理台本中展开：他原本希望她不在，读到关系结束，流泪可能来自解脱，而不是失去爱人的悲伤。（p.483—484）

这个例子说明，**事件梗概和动作表面还不够决定潜文本**。但“作者知道他是解脱”也不等于影片已表达解脱，后续仍要靠行为、上下文、声音与表演提供依据。

本章的“喜欢的车库、睡衣小孩、海滩与爆炸”等例子，则说明局部受欢迎不能证明整体成立。（p.479—480）在 AI 制作里，对应的是某个已花钱生成的好镜头，不因此自动获得保留资格。

### 13.3 原创教学对照：十版剧本和三套事件方案的区别

| 工作方式 | 过程 | 结果倾向 |
|---|---|---|
| 较弱 | 让 AI 写完整剧本→改得更感人→多加金句→人物哭得更重→换标题→继续保留全部精美镜头 | 版本数增加，人物欲望、行为与结尾因果没有变 |
| 较好 | 先写三套行动机制不同的大纲→比较每套的关键选择与结局→选一套展开动作与反应→检查信息和制作条件→再写对白并试生成关键场面 | 先在便宜的层面筛选，修改能针对明确缺口 |

所谓“行动机制不同”，例如同一场关系修复可以通过承认错误、兑现承诺、尊重一次拒绝等不同选择完成。仅把背景换成雪天、雨天和黄昏，不算三套结构方案。

### 13.4 观点／理论是否过时

| 原书主张与位置 | 判断 | 今天的处理 |
|---|---|---|
| 先事件组织，再细化表达，p.480—486 | 仍适用 | 适合减少 AI 长篇起草后只修辞藻的循环 |
| 创造备选、敢于删除，p.481 | 仍适用 | 比较差异，不以生成数量代替审美判断 |
| 讲给人听，观察反应，p.482 | 仍有价值 | 用复述、困惑点和关注点收集反馈，不只等一句“感人” |
| 必须讲得好才可能拍得好，p.482 | 需要条件 | 口述能查事件，不能充分验证节奏、声音、表演和纯视觉表达；还需分镜或粗剪 |
| 月份、卡片尺寸、处理本页数与淘汰比例，p.480—485 | 经验方案 | 按短片容量与团队流程缩放，不照搬长片篇幅 |
| 从外到里最缺乏创造力，p.485—486 | 个人方法偏好 | 作者在末页也承认其他方法能写出佳作；可从一句对白或试镜开始探索 |
| 绝大多数听众热情之前不应前进，p.482 | 不宜机械执行 | 少量反馈用于找问题，不能把朋友喜好或 AI 打分当作市场验证 |

### 13.5 AI 短片适用性与使用方案

**适用性：很高，尤其适合已有大量草稿和素材，却迟迟无法定稿的项目。**

1. 用几行话定义当前故事，不让 AI 首轮就补满长剧本。
2. 生成少量实质不同的候选，比较欲望、代价、关键选择、结果和制作负担。
3. 选定后写步骤大纲；每场一两句，先不追求文学修饰。
4. 展开场景：人物如何行动、对方如何回应、哪里转折、什么未被说出。
5. 查背景、主题、信息与人物逻辑，完成声画剧本与必要分镜。
6. 有针对性地试生成，检验关键表达是否成立；若试验带来新发现，允许回到上一步。
7. 每轮只设一个主要修改目标，保存变更理由，复查它是否影响其他铺垫。
8. 把不用的好镜头放入素材库。复用条件是符合新故事的时空、动作和意义，而非已经付过成本。

**可交给 AI 的指令：**

> 暂不写完整对白。根据相同人物、场景和制作约束，提出三套行动机制不同的事件大纲，分别列出欲望、阻力、选择、代价、结局和主要风险。推荐时引用方案差异，不使用空泛分数。选定后再展开动作／反应；重写时列出变更前后与原因，不为保留漂亮镜头强接情节。

**验收：**这一轮修改改变了什么事件关系，为什么能解决原问题？如果答案只有“更优美、更催泪”，还需继续定位问题。

## 十四、把 11 章接成一套可执行流程

### 14.1 从选题到制作，不必每步都生成长文

| 步骤 | 用哪些章节 | 人负责的判断 | AI 可以交付什么 | 通过条件 |
|---|---|---|---|---|
| 1. 明确材料与限制 | 3、19 | 哪些事实可信，哪些资源可用 | 一页背景与事实清单 | 事实、假设和待查项分得开 |
| 2. 明确观看承诺 | 4 | 希望观众等待什么 | 类型承诺句、不同事件候选 | 开头与结尾属于同一叙事任务 |
| 3. 选择意义与人物关系 | 6、17 | 哪种改变值得表达 | 价值＋原因、人物矛盾与配角目标 | 主题有行动依据，对方不只是工具 |
| 4. 修复事件进展 | 9、14 | 哪项阻力有分量，何处必须换办法 | 尝试—结果—新限制表 | 失败有持续影响，代价与行动相称 |
| 5. 分配信息 | 15、16 | 何时想让观众好奇、担忧或理解 | 必要事实与信息差表 | 基本行为可理解，揭示有依据 |
| 6. 组织节奏与场景连接 | 12 | 哪些段落值得停留 | 场景功能、删并建议、声画过渡 | 连接有意义，情绪与信息不空转 |
| 7. 转为制作文本 | 18 | 什么必须清楚可见／可闻 | 声画剧本、分镜需求、关键资产状态 | 心理已找到表达路径，连续性可检查 |
| 8. 试验、反馈与重写 | 19，并回查相应章节 | 哪个问题最影响观看 | 关键镜头试验、反馈整理、最小改稿 | 修改解决原问题，并未破坏其他因果 |

这是往复流程。先做一小段试验，有时能帮助发现故事；但不能因为试验画面好看，就跳过对整片意义和信息的判断。

### 14.2 一个贯通示例：同一场“修门锁”如何调用多章

**以下为原创教学示例，仅作事件与制作规划，不是已验证完成的短片。**

**创作目标：**表现母子从互相替对方作决定，走向一次具体合作。母亲想保有自主，孩子想参与她的生活；不把母亲设为无能，也不把孩子设为必须牺牲自己的人。

**步骤大纲：**

1. 门锁卡住，母亲试了两次，孩子在门边等；这个不便先成为两人共同面对的事实。
2. 孩子提出出钱处理，母亲拒绝，把钱推回去，拿出自己的工具盒。
3. 孩子伸手去拿工具盒，母亲将它收近；他停下，意识到自己又在代她决定。
4. 孩子改问她需要自己做什么，母亲没有立即回答，先摆好自己要用的工具。
5. 她把工具盒移到两人之间，给孩子留出位置，让他参与一个明确的小任务。
6. 门再次打开；两人把用完的工具放回盒中，合作已发生，更多关系问题留在片外。

这里不靠“母亲其实病重”翻转意义，也不需要证明一次修理已解决所有家庭问题。

| 所用章节 | 这个示例中的实际决策 |
|---|---|
| 3：背景 | 查清门、锁、工具和空间关系；需要什么操作就核实什么，不凭想象设计维修流程 |
| 4：类型 | 主要承诺是关系如何松动，不以险情标题伪装成惊悚 |
| 6：意义 | 工作主题是“合作开始，因为双方不再替对方决定”；第 4、5 步必须支持它 |
| 9：进展 | 出钱、直接接手相继受阻，孩子改为询问，不能只换个说法继续强求 |
| 12：布局 | 盒子被收近再移到中间，是一组关系变化；门从卡住到能开，承担前后呼应 |
| 14：阻力 | 阻力是自主与参与的张力，不用把任何一方写成恶人 |
| 15：解说 | 无须对白讲完多年关系；钱、工具盒及两次递接足够建立当前矛盾 |
| 16：信息与视点 | 让观众看清母亲已准备工具，避免误读为她什么都不会；不靠结尾补一句话才解释行为 |
| 17：人物 | 母亲既拒绝被接管，也愿意合作；孩子既想帮忙，也要学习接受边界 |
| 18：文本 | “尊重”落实为停止伸手、先询问；“接受”落实为共同空间和具体协作 |
| 19：重写 | 若试拍后看不清盒子位置变化，先修观看顺序与动作，不先加主题旁白 |

**最先验证的制作点：**观众能否区分“夺走工具替她做”与“被邀请参与”？如果看不出来，应该调整动作、站位和反应，再考虑镜头是否足够漂亮。

### 14.3 可复用的最小工作表

不必为每个故事填几十项。用下面这张表，就能覆盖本轮最主要的问题。

| 项目 | 填写要求 |
|---|---|
| 当前目标 | 谁在什么时间限制下想得到什么？ |
| 世界约束 | 哪些规则真正限制行动？哪些事实尚未核实？ |
| 主要承诺 | 观众此刻在等一个什么结果？ |
| 人物矛盾 | 他同时受哪两种诉求牵引？各有什么行动证据？ |
| 对抗力量 | 谁或什么在阻止他？为什么不是轻易可以绕开？ |
| 进展 | 一次失败使哪些办法失效？下一步怎样改变？ |
| 意义 | 最后什么价值改变，主要因为什么行动？ |
| 信息 | 哪项事实必须何时知道？观众与哪个人物存在信息差？ |
| 声画表达 | 关键变化由什么动作、声音、对白和反应承担？ |
| 连接与意象 | 相邻场景怎样连接？重复物件的用途或关系是否改变？ |
| 制作验证 | 哪项关键表达最容易失真？准备怎样试验或替换？ |
| 本轮修改 | 只先解决哪个主要问题？改完用什么证据验收？ |

### 14.4 一条综合审稿指令

> 请依据《故事》B级章节的方法分析下方短片稿，先诊断再修改。
>
> 1. 区分已知事实、虚构设定与待核实项；引用原稿，不补写缺失事实。
> 2. 用一句话写出主要观看承诺，以及结尾的“价值＋原因”。若稿件尚不能支持，就标出缺口。
> 3. 按场列出：人物目标、行动、对抗力量、结果、下一策略、新增信息、可见／可闻依据。
> 4. 针对关键信息，比较观众与相关人物的获知时点，检查反转是否诚实、有依据。
> 5. 检查人物矛盾、配角目标、旁白功能、节奏与过渡，分清结构缺口和制作表达缺口。
> 6. 只挑最重要的三个问题，每项提供“原稿证据—影响—最小修改—验收方法”，并标对应章节。没有证据的问题写成待验证假设。
> 7. 若修改涉及核心事件、信息顺序或结尾，说明会牵动哪些铺垫。若现稿已成立，明确保留有效部分，不为显示修改而改写全部。
>
> 不套固定三幕比例，不要求每镜反转，不把悲惨设定当人物深度，不以新增疾病、事故或贵人救场解决问题。AI 评价是修改参考，不能冒充真实观众反馈或平台验证。

## 十五、制作前最后核对

- [ ] **可信：**事实与虚构已标明；生活规则没有为了结尾临时改变。（第 3 章）
- [ ] **承诺：**片名、开头和结尾对主要体验的承诺一致。（第 4 章）
- [ ] **意义：**删去片尾口号，关键行动仍能支持主题；虚构结果未被当成现实定律。（第 6 章）
- [ ] **进展：**中段的失败确实改变后续办法；没有只是重复受苦。（第 9 章）
- [ ] **布局：**场景有取舍与连接，关键反应有被看清的时间。（第 12 章）
- [ ] **阻力：**困难与人物欲望有关，不靠污名或纯粹加惨成立。（第 14 章）
- [ ] **信息：**观众能跟上当下行动，旁白、对白和画面各有功能。（第 15 章）
- [ ] **揭示：**信息来源、巧合、视点和强烈行为经得起回看。（第 16 章）
- [ ] **人物：**矛盾有连续行为证据，重要配角保有自己的目的。（第 17 章）
- [ ] **表达：**抽象心理已找到声画路径；意象有情境依据，必要资产连续。（第 18 章）
- [ ] **重写：**本轮解决了一个可说明的问题；没有因为已生成就强留素材。（第 19 章）

**实际使用建议：**把一份正在写的短片稿放入综合指令，先处理最影响理解或情感的三项。若还没有稿件，从第 3、4、19 章开始；若已进入制作，先用第 15、18 章检查信息与动作是否能够被观众读到，再回查结构。以作品是否变得更清楚、更可信、更有选择的分量衡量学习效果。
