# 拉片分析框架（短视频爆款逐镜拆解）

> 本文件是分析阶段的"知识底座"。完成素材抽取与 ASR/OCR 后按本框架产出结论。
> 目录：① 分析维度总览 ② 开头钩子 ③ 叙事结构 ④ 情绪工程 ⑤ 声音设计 ⑥ 字幕语法 ⑦ 选题公式 ⑧ AI 剧情短片落地 ⑨ 字段口径与枚举

## ① 分析维度总览
每条片固定回答六件事：**讲了什么（选题）｜怎么开头（钩子）｜怎么排布（结构）｜镜头怎么切（分镜/转场）｜声音怎么推（BGM/音效）｜文字怎么分工（字幕）**。逐镜表是证据，结论必须能回指到时间码。

## ② 开头钩子
- **黄金时间**：前 3 秒决定停留，前 15 秒决定完播。
- **钩子公式**：反常识细节（价格/数字/物件）＋ 1 秒感官特写快切 ＋ 一镜到底的悬念现场 ＋ 记忆碎片对白。
- **记忆碎片手法**：画面连贯不切，声音在多个时空/说话人间跳跃，观众看不懂细节却感知"有故事"，为"搞清楚"而留下。
- **核心原则**：钩子不讲清故事，只制造"未完成的信息缺口"。
- 常见钩子点：价格/数字、危险（强冲突词）、身份/关系悬念、结果前置、直接提问、反差身份。

## ③ 叙事结构
- 情感剧情片高频结构：**现实钩子 → 年代闪回 → 时间蒙太奇 → 重逢 → 真实佐证**（环形报恩）。
- 八拍骨架：现实钩子｜困境展示（立弱者）｜善意建立（旁人质疑反衬）｜情感加码（一顿饭→出路→改变命运的物件）｜第一次离别（挖坑）｜时间蒙太奇（一次善拉伸成一生守）｜重逢对话（三连问+三句答）｜真实佐证+落版。
- **环形闭环**：让开头与结尾复用同一个动作（如"递包子"在三代人间闭环），是最隐蔽有力的结构设计。
- 节拍表需标注：激励事件、首次点题、小高潮、至暗时刻、回到现实、总爆发、落版的精确时间码。

## ④ 情绪工程
- **曲线读法**：用实测 RMS/归一化能量画曲线，叠加幕分区与转场点；找"压抑区、假高潮、总爆发"。
- 手法口诀：前 80% 压着走（音乐小、配器稀、靠细节撩）；一次假高潮（涌起又收回）再给真爆发；冲击音一次比一次重、转场一次比一次亮；金句由"做事的人"轻描淡写说，不喊口号。
- 爆发点位置（emotion_peak_sec / duration）是横向对比的关键指标。

## ⑤ 声音设计
- **BGM 三段式**：低压铺底（钢琴/弦乐，长期 -15～-18dB）→ 假高潮涌起收回 → 关键段全频段铺满（约 -10dB）。
- **音轨四层**：BGM ＋ 对白/旁白 ＋ 转场音效（如 whoosh）＋ 真实环境声（街市/雨声/灶火/咀嚼）。
- **峰值管理**：同一转场音效多次出现时逐级加码，形成"一次比一次重"。
- **选曲逻辑**：选"歌词即剧情"的爆款 OST，等于让歌曲替你完成结尾抒情；方言对白增真实感。
- 关键瞬间（怔住、空等、接物）音乐主动压低或留白。

## ⑥ 字幕语法（5 类，位置即功能）
1. 对白字幕：底部居中，白字黑描边。
2. 内心/旁白：左侧区域、暖黄色、带圆括号（）——与底部对白形成"现实声 vs 记忆声"双声道。
3. 年份标签：中上部、直角引号「」——零成本交代时空跳转。
4. 新闻/资料字幕：多行小字铺下部——真实素材段交代事实荣誉，制造纪录片权威感。
5. 落版主题词：黑底居中、毛笔手写体——留下可传播的片名符号。
> 零配音方案：底部对白＋左侧括号心理＋「年份」三层文字即可撑起叙事。

## ⑦ 选题公式
**真实小人物 ＋ 一个重复了几十年的动作 ＋ 一个反常识数字 ＋ 一次重返/重逢。**
可平移：摆摊人、修鞋匠、摆渡人、乡村教师、守塔人、补锅匠……先找"一个动作坚持 N 年"的真实新闻，天然带情感与话题。

## ⑧ AI 剧情短片落地（8 步工作流）
1. 先定色彩双轨再出图：现实冷蓝灰、回忆暖黄做旧，prompt 写死色调词。
2. 角色一致性：建"角色锚定描述卡"（年龄/发型/服装/标志物），复用定妆参考图。
3. 特写优先：AI 最擅长且不易穿帮手/物件/食物/面部特写，用其叙事；多人全景少用或用真实素材。
4. 转场统一：3–6 帧白闪＋同一音效，一种语法用到底即成风格。
5. 时间流逝：年份卡＋同机位不同人物服装快切。
6. 音轨四层铺，结尾换歌词即剧情的 OST。
7. 字幕三层模板，真实段加新闻字幕。
8. 真实素材是信任锚点：结尾 15–20s 放真人照片/新闻，规避"全是 AI"的虚假感。

**避坑**：不让 AI 生成复杂多人/大幅肢体动作（用特写与剪辑绕过）；钩子不讲清故事；时空关系用字幕卡而非长旁白；真实素材注意版权与事实核对；色调/字体/转场不超过 2–3 种。

**底层逻辑一句话**：用"真实"背书、用"悬念"留人、用"时间"蓄力、用"重逢"引爆、用"符号"传播。

## ⑨ 字段口径与枚举（多片统一，保证可汇总）
YAML 字段名固定；取值优先用下列枚举，新增需登记；同义词统一（"闪白/过曝"统一记 `白闪`）。

| 字段 | 枚举值 |
| --- | --- |
| source_platform | 抖音 / 快手 / 视频号 / 小红书 / B站 |
| content_type | 情感剧情短片 / 悬疑反转 / 搞笑段子 / 知识口播 / 纪实采访 / 混剪 |
| true_story | true / false |
| hook_type | 反常识数字 / 物件特写快切 / 强冲突台词 / 一镜到底 / 记忆碎片对白 / 直接提问 / 结果前置 / 反差身份 |
| structure_type | 现实钩子-年代闪回-重逢-真实佐证（环形报恩）/ 单线顺叙 / 倒叙 / 多线交织 / 三幕反转 / 闯关升级 |
| transition_signature | 白闪+whoosh / 硬切 / 叠化 / 匹配剪辑 / 遮挡转场 / 运镜转场 |
| color_system | 冷暖双轨 / 单色调 / 高饱和 / 黑白+点缀色 |
| bgm_structure | 三段式（压-假高潮-爆发）/ 单曲贯穿 / 静默为主 / 节奏卡点 |
| subtitle_layers | 整数 1–5 |

**汇总建议**：同类对比优先看 hook_type、structure_type、transition_signature、爆发点占比（peak/duration）；多条情绪数组按 t/duration 归一到统一时间轴叠加找共性起伏；镜头节奏同时记"段落镜头数"与"含蒙太奇切点数"。
