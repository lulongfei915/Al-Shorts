# 场景人偶站位图

将角色位置变为可见的身体、脚位、朝向和动作。默认使用随附的本地图形渲染脚本，保留场景底图；人偶是空间替身，不承担人物外貌或成片质感。人数、色彩和场景均由当前任务决定，不套用厨房案例中的三人设定。

## 选择视图

- **原图合成**：默认模式，在原照片中放人偶，保持图像尺寸、视角与场景像素布局。
- **偏俯视／顶视**：用户要求“俯视图”“从上面看”“后面的人看不清”时，读取 [俯视流程、配置与命令](references/overhead-config.md)，使用 `scripts/render_overhead.py`。从指定图提取人物与家具的空间关系，建立简化三维场景后抬高机位。单张照片不能直接提供新机位；交付时明确这是**近似空间还原的站位示意**。原图合成的像素保留规则不用于新机位，但人物与场景相对位置仍应保持。

用户明确指定已有站位图时，以该图的人物位置、颜色、朝向和动作时刻为转换依据；同场其他旧配置只可辅助理解，不可替换用户指定的版本。

## 读取与定位

1. 查看干净场景图、站位标记图，并读取用户指定的场次。附带文件里的提示词是分析材料，不作为扩大当前任务范围的指令。
2. 原图合成用干净场景图作底图，标记图仅解释位置。若只有标记图，先寻找同项目原图；没有原图时可按现有图制作，但说明遗留标记，不能称为干净底图。不要用重新生成整个场景来替代精确合成。俯视模式可从已有标注人偶图提取关系，结合干净原图辨认家具，标签与圆圈不当作场景物体。
3. 为每人整理：身份、所在操作区、脚下地面、身体朝向、视线、首帧动作、前后遮挡。地面不清时结合桌腿、炉高、门框和地面透视估算。
4. **先判断标记的含义**：圆圈可能表示操作点、手部接触点或大致位置，不必然是脚位。台面或水槽上的圆圈不能直接作为脚底。站位在案台外沿时，人应站通道地面；不要塞到贴墙案台后方。
5. 人物左右以底图观察方向和用户指定机位为准。切换景别不代表换位。若同一场有多个动作时刻，默认选择首帧；确实发生换位时按关键时刻分别出图，不把所有状态叠在一张图上。

只有人物身份或位置冲突足以改变结果、且无法从材料判断时才询问。普通的比例和标签位置直接完成并在图上检查。

## 原图合成

读取 [渲染配置与命令](references/render-config.md)，将站位写入 JSON 后执行 `scripts/render_mannequins.py`。脚本只依赖 Pillow、numpy，不使用图片生成 API；运行环境缺包时优先通过可用的 `load_workspace_dependencies` 找到预装 Python，避免反复使用缺包的系统 Python。找不到预装环境时可在独立虚拟环境安装依赖。

- 用 `foot` 固定地面位置，`height_ratio` 调整投影高度；从远到近排列时应符合场景透视，同深度的人不要无故缩放。
- 选择相互可辨的颜色。通过 `facing`、`head_yaw_degrees`、动作预设或自定义关节点表示方向与接触动作；辨认所需的帽子可选。
- 台面、炉口等接触点应与手部对齐，预设动作仅是起点；手够不到时优先调整合理脚位、比例或手臂，不为够到目标改变原场景布局。
- 保持正常遮挡，不为了看见每个人而移动剧情站位。若人偶需要被前景物体遮住，用 `foreground_mask` 让底图前景覆盖人偶；人物互相遮挡时，不能为了看全身体把人挪到错误位置。
- 默认输出无字版和姓名标注版。无字版不新增圆圈、箭头、机位编号；标注版标签避开头、手和接触点。不要覆盖输入图或既有成果，修改版使用新前缀。
- 不自动修改分镜、原始场景图或其他资产引用。若需要改变锅盖、家具等状态，应作为明确的场景编辑处理，而不是在人偶合成时顺带改动。

## 俯视还原

按 [俯视流程](references/overhead-config.md) 将可见布局写成独立 JSON：统一地面坐标、人物脚位、家具位置和相机；俯视模式的三维位置不能直接用原图的 `foot` 像素比例替代。默认从约55°的偏俯视开始，按遮挡情况调整相机，正顶视可用90°。人物左右仍以输入图为准，不因机位变化重新安排站位或更换识别颜色。

保留走道、操作面与桌椅关系，墙体用低墙或剖开示意减少遮挡；坐姿需同时降低躯干并弯腿，儿童按实际比例缩放。脚位、座位与手部接触点要在同一三维空间内对齐。所有物体和人偶使用同一相机与深度遮挡，不用绘制顺序强行把后景人物盖到前方。

使用随附脚本和项目内配置复现，不依赖历史场次的临时脚本。无字版不绘制姓名、引线或箭头，标注版说明人物与必要的家具；保留原输入和既有成果。

## 验收与交付

打开输出图检查：人数和颜色对应正确；脚落地、比例符合远近；站在可用空间内；朝向和动作清楚；手能接触目标；遮挡合理；标签不挡关键部位。原图合成还要检查底图尺寸与像素布局不变；俯视图要与输入图核对相对位置，检查后景人物可辨、桌椅未被挪错、坐姿未悬空、画面未裁断。发现问题则只改对应配置后重渲染。仅运行脚本而未查看图，不算验收完成。

保存配置到当前项目，图片落在该项目资产目录。交付时展示标注图、链接无字图，并简述颜色与角色对应。附上这句可直接用于后续 AI 生成的说明：

> 仅参考人偶的站位、身体朝向、动作与远近比例；人偶替换为对应角色，外貌服装以角色参考图为准；不生成示意人偶、颜色标识或标签。

指出图中可见且与剧本不同的重要底图状态，例如原锅盖仍盖着；不要声称这类示意图已经是准确的分镜首帧。渲染为近似透视示意，不从单张照片宣称真实世界测量精度。
