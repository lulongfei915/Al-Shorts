## 4. 结尾收束拆解（尾段钩子）

**收束公式（四步兑现）**：行动代替台词（回家+手上已有枕头）＋ 第四次"挺好的"语义反讽（父亲"原来那个挺好的"）＋ 问答权反转（父亲问儿子，儿子承认"挺累的"）＋ 道具替人点题（设备屏幕三屏输出金句）。

- **02:00 产品长镜头**：01:52–02:05 共 12.8s 手抚枕特写，无演示、无旁白卖点，把观众注意力用静默逼向 logo。
- **02:05 不交代心理**：没有"他决定回家"的台词，拎包进门、"回来了""正好饭还热着"即完成；失业、知情、和解全被省略。
- **02:21 第四次"挺好的"**：前三次都是隐瞒（16.4s/51.2s/86.0s），第四次是父亲"不想让孩子花钱"，口头禅从谎言翻转为爱。
- **02:43 问答权反转**：前112秒全是外星人在问，尾段父亲反问"最近累不累"，一直给答案的人开始答问题。
- **03:01 调查体点题**：三屏文档（原判断→调查结果→结论修正），与开场"根据我们的调查"首尾呼应，金句由道具而非角色说出。
- **03:08 反广告落版**：最后5.3秒黑底主题句，无 logo、无话题、无 CTA；用最值钱的广告位换截图传播。

## 8. 可复用方法论（品牌情感片结尾）

**① 品牌尾段公式**：产品在75%处入场（痛点已立）→ 产品被"送出去"而不是被展示 → 一句功能台词带过 → 不展示使用结果（只展示被爱）→ 道具替人输出金句 → 片尾让给主题句，不放品牌卡。
可平移：适老产品（鞋/血压计/按摩仪）、睡眠产品、父母礼品盒、儿童学习产品——所有"购买者≠使用者"的品类。

**② 产品叙事五拍（约30秒）**：
1. 质感特写（5s）：手抚产品，logo 借光入镜，无卖点旁白
2. 送礼动作（6s）：产品装进容器，双手递出（容器=仪式感）
3. 被拒绝（4s）："原来那个挺好的"制造真实感
4. 旧物对比+一句功能（5s）：旧产品特写 + 生活化功能台词
5. 之后不再出现：产品交给关系，对话接管结尾

**③ 落版文案公式**：「我们总以为 X = A；可有时候，-A 也是 X」。本片："爱=不让他担心 → 允许他为你担心，也是爱"；把品牌主张上抬到"如何去爱"，不出现产品名。

**④ 制作工作流（AI 短片）**：先写"删掉产品也成立"的故事；产品只做手能做的动作（抚摸/开盒/递出/摆放）；logo 丝印进道具；金句由道具屏输出；结尾撤声；片尾不挂品牌；功能台词≤1句且由购买者说。

**⑤ 避坑清单**：
- 不要让产品"治好"任何人（不展示睡好，只展示被爱）
- 不要让受赠者立刻夸产品（父亲全程没夸枕头）
- 不要在结尾补品牌大卡+二维码
- 功能台词不超过一句，说第二句就是广告
- 口头禅复现必须够次数，最后一次要翻转语义

**⑥ 底层逻辑一句话**：让产品成为"爱被说出口"的道具，而不是被记住的主角；真正的高潮是一顿饭，真正的落版是一句没有品牌名的话。
