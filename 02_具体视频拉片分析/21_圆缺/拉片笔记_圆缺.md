## 1. 全片概览

《圆缺》由“我们来自月球”发布，页面声明内容由AI生成，作品说明称全片由小云雀Seedance2.5制作。实测69.533s，横屏1024×576、30fps。它把秋千、祝寿、教室、升学宴、宿舍、办公室、恋人、宠物、老屋、晚年伴侣与母子回忆放在一起。没有证据证明这些是同一人的连续一生，也没有足够信息指认开场成年女性的具体亲属身份。

主体采用成对对照：每组先让关系被一个动作看见，再保留空间或动作，切换到关系缺席后的状态。教室的“毕业快乐”、宴席后的清理、空宿舍，与猫的告别布置和墓碑属于不同程度的告别；只有后两类有明确死亡意象。办公室独坐、火锅桌的玩具熊都不提供唯一因果，不能代写成确定的裁员、倒闭或恋人死亡。

最后的结构不是继续“越来越惨”：52.767s先出现秋路独行的老人，54.600s转向年轻母亲与拿风车的男孩，方向变成“缺→圆”。59.733–61.500s用10格快闪逆序回访，61.500s再回秋千。它让观众重听同一句“永远都在这”，用已经看过的失去重新解释它。

## 4. 开头钩子拆解

**公式：熟悉的陪伴动作 + 一个关于永远的问题 + 立即可信的回答 + 4.433s后的同位置空缺。**

| 时间 | 可见/可读证据 | 叙事作用 |
| --- | --- | --- |
| 0–1s | 女孩正面荡秋千，成年女性在身后，户外晴朗。 | 用动态和陪伴关系形成可识别场面，不先铺大段设定。 |
| 1–3s | “那你会一直在这推我吗”；回答“当然啦 / 永远都在这”。 | 把日常动作提升成长期承诺；观众知道“永远”难以兑现。 |
| 3–4.433s | 秋千仍在运动，空间与人物继续完整。 | 让幸福先成立，给后一镜的空位一个参照。 |
| 4.433–6.500s | 相似构图中只剩雨中秋千。 | 突然让“谁不在了”成为问题，并教会观众后续成对阅读规则。 |

它属于直接提问钩子，问题也是结尾的回声。这里没有证据支持“前1秒物件快切”“多时空对白碎片”或“一镜到底悬念”；开头是一个连贯关系场面，反差在第4.433秒才到来。前3秒的吸引力分析是创作判断，未测实际停留率。

三个可学习点：动作比关系标签先到；“永远”比“我很想你”更适合等待结尾重听；第一组保留同一秋千，使观众无需解释就理解时间改变了什么。首镜4.433s不算极快，证明钩子不只能靠高切换频率。


## 5. 脚本框架还原

**结构类型：成对对照串联 → 局部反向回忆 → 逆序回访 → 首尾复现。** 不是一位主人公从出生到死亡的完整传记，也没有“寻找恩人—重逢—真人佐证”的报恩线。

1. 提出承诺：女孩问会不会一直推秋千，得到肯定答案。
2. 第一次空缺：秋千还在，人不在，建立理解规则。
3. 扩展关系半径：家族、同学、乡邻、室友、同事，形成不同观众都可认领的生活入口。
4. 收缩到私人亲密：拍照、喂猫、抱孩子、递花，动作越来越具体，告别含义也变重。
5. 反转对照方向：先呈现秋路独行，再回到母子同行，给出“回看”的语义。
6. 快速逆序召回：用已建立的画面记忆回到更早的团聚。
7. 重听承诺：秋千复现，不再给新的事件，改变旧对白的意义。
8. 主题落版：把众多局部关系收束为关于一生的句子。

### 倒序段的准确顺序

秋路独行老人 → 老年伴侣递花 → 老屋亲子 → 活着的猫 → 火锅女子 → 办公室庆祝 → 寝室伙伴 → 升学宴 → 投影课堂 → 厅堂祝寿 → 秋千（进入长镜头复现）。第一格仍是独行老人，因此不应概括为“十格全是团圆”。它更准确地说是逆序回访前面的关系节点。

### 为什么重复没有变成纯粹堆叠

每组保留一个位置或动作，但“缺”的类型不同：空物件、空空间、散场劳动、独坐人物、替代玩具、死亡布置、空巢等待、墓碑。它们使视觉句式稳定而语义变化。母子一组再翻转顺序，最后将观看方向整体反向。可讨论的风险是中段规则过于稳定，第二三组之后观众容易预测下一次“变空”；创作时应通过缺席状态的变化和段长变化避免机械重复。

## 8. 可复用方法论

### ① 选题公式

**一种曾经稳定的关系 + 一个能固定位置的日常动作/物件 + 相同空间里的缺席状态 + 结尾重新听懂的一句承诺。**

可以平移到老店的固定座位、家门口的接送、球场约定、每年一张合影、固定节日的一桌菜。先找关系中“以前一直这样”的小动作，而不是先找催泪台词。每个新故事仍需自己的事实与细节，不直接搬运本片的人物组合和对白。

### ② 结构模板与伸缩

| 模块 | 最低配置 | 原片做法 | 伸缩原则 |
| --- | --- | --- | --- |
| 承诺 | 1个动作、1问1答 | 秋千问“会一直在这推我吗” | 让观众先理解关系，别开场堆说明。 |
| 第一次变化 | 同一空间的前后两态 | 晴日有人→雨中空秋千 | 首组应最易读，先教语法。 |
| 平行变奏 | 3组不同性质的告别 | 集体生活延伸到亲密关系 | 30秒版用3–4组即可；别只按人数堆砌。 |
| 顺序变化 | 1次“缺→圆” | 独行老人→母子同行 | 给“回望”合理入口，不要求所有故事都倒放。 |
| 回访 | 只重用已经读懂的镜头 | 1.767s、10个短镜头 | 5–6帧是原片结果，不能当通用最佳值；新内容需更长阅读时间。 |
| 回声与落版 | 完整重听承诺，最后一句主题 | 秋千约5.167s、文字约2.866s | 留出句子与主题阅读的时间，快闪后要恢复呼吸。 |

### ③ AI制作工作流（由本片拆解推导的建议）

1. 写“关系—日常动作—缺席状态”三列表，先确认每组的含义；毕业、搬走、关系疏远与死亡要区分。
2. 为每组制作空间锚点：机位高度、焦距感、主轴、固定道具、人物所在位置。先出一张清晰底图，再据同一图生成关系变化后的状态。
3. 明确哪些元素必须保持：秋千支架、前景桌边、火锅座位、窗框、屋门；哪些允许改变：季节、照明、人物数量、道具状态。
4. 动作匹配优先于滤镜匹配。若递花跨成放花、喂食跨成抚摸，手的位置、视线和运动方向要能接住；必要时分两镜拍清，别强做生成变形。
5. 给“缺席”设计变化：空椅、独坐、散场清理、替代物、留下的人；保留具体差异，避免每组都全员消失。
6. 先完成常规速度粗剪，确认静音看也能理解关系变化，再放短对白。群像场景尤其核对人脸、手部、座位与空间是否跳变。
7. 从已出现镜头中挑选回访素材，按逻辑排序。快闪只做记忆唤回，不负责介绍新人物；首尾复现片段可以直接复用已确认素材。
8. 最后统一字幕与主题落版，复核音乐和对白实际听感；分别检查声学峰值和情绪转折，不拿归一化曲线代替观众测试。

### ④ 情绪口诀

先让人看见“在”，再让位置留下“缺”；最后让“曾经在”回来，原话就会变重。

### ⑤ 避坑与可检验问题

- 别把同构图当作万能催泪：第一态必须有能辨认的关系动作，单纯“有人/无人”容易沦为场景展示。
- 别把所有空位都写成死亡：告别有毕业、迁离、散席、分手、空巢与丧失等不同含义；有证据才写唯一原因。
- 别强行统一人物：本片采用多个关系入口，身份无法确认的地方保留开放阅读。
- 别把暖色等同过去：秋路独行也是金色；情绪由人物、光线、季节、动作与声音共同建立。
- 别把倒序段说成“十格都是圆满”：第一格仍是独行老人；它首先是按前文顺序回溯。
- 别照搬固定三幕音乐/假高潮：本次未核实具体乐曲与音效；框架必须服从作品证据。
- 可测试两个版本：保留与删去中段一组，比较是否仍能读懂规律；保留与删去首尾同句，比较回声是否成立。测试结果需另收数据，不预设有效率。

### ⑥ 对传播的解释边界
